# 手機優先健康檢查

**內部機密｜營運與技術規範。** 此技能不得寫入、顯示或傳送真實客戶個資、金鑰或完整輸入資料。

當使用者說「健康檢查」或要求手機優先的穩定性掃描時使用本技能。

## 執行

1. 執行 `npm run health:check`。它以 390px 手機請求輪巡首頁、服務就緒端點與每張功能卡片頁。
2. 檢查報告 `reports/screen-health/latest.json`：確認所有路由 HTTP 正常、沒有應用程式錯誤頁、回應時間沒有異常。
3. 需要做狀態審查時，以系統測試資料在手機寬度驗收操作流程、結果卡片是否出現、是否橫向溢出或卡住。這是診斷，不是功能修改。

## 安全復原界線

- 指令只有在服務不可用時，才可重新啟動本機前端服務；不清除快取、不改程式、不改資料、不改卡片。
- 涉及功能、文案、視覺、卡片、排版或流程的問題，一律停止於診斷與回報，等待使用者授權後才處理。
- 不以健康檢查名義自動修正業務邏輯。

## 回報

正常時只回報：手機優先健康狀態、通過卡片數、是否需要服務復原。

異常時回報：受影響頁面、手機客戶可見症狀、是否已安全復原服務，以及需要使用者決定的功能或設計修改。不得以真實客戶資料作為例子。
