# 首頁神獸入口視覺融合

這是工程視覺技能，不是命理運算技能或權威來源。只處理本次點名入口；開始前列出必要檔案及允許變更，先查 Git 差異，保留其他工作。功能、API、命理來源、文案及其他卡片保持凍結。新增範圍須有明確授權，不因本技能自動美化全站。

## 核實素材

### 缺陷定位與交叉細修（業主追加）
每輪先明確告知缺陷部位與現象，再局部修正；不得只報「融合不好、繼續細修」。以原卡、修改前後及實際首頁交叉比對，反覆修正已定位缺陷，同時檢查其他部位是否退步。原因未證實須標為假設，不能以同色或程式測試通過代替視覺證據。執行與紀錄格式見 [精準合成的缺陷閉環](references/precision-compositing.md#缺陷定位交叉比對與局部細修閉環)。

依指定集合查正式神獸卡（四大神獸／二十八宿、成獸／幼獸），確認卡 ID、form、原圖及實際 renderer。不能猜同名圖、拿戰鬥姿勢替代本體或生成新獸。只有確實無法判定時才詢問。

已核對的來源鏈（每次仍檢查當前程式）：

## 構圖與邊界

保留完整本體、原色與比例，使用 contain 等比呈現，不裁角色、不拉伸、不加改色濾鏡。原場景一起融入入口；可局部調整卡底與環境外緣的明暗銜接，保留寬鬆環境，四周略弧或自然不規則，消除明顯矩形內嵌圖卡。不造聚光暈圈或規則橢圓相框；若需要本體跨提示，依後文以前景專屬輪廓分層，不能用通用遮罩。遮罩須避開角色細節，逐張確認，不能照搬同一遮罩而切掉尾巴或頭部。

外卡沿用首頁既有尺寸規則。先量測畫面順序的上下鄰卡，再調內部圖片比例及間距；不得為放大圖像撐長本卡，更不得修改鄰卡湊齊。尺寸規則在 `app/globals.css` 的 `--home-entry-min-height` 等入口規則；不要將某次 240／264px 實測值硬碼為全站規格。

標題、文字及裝飾是否移除，依當次授權。玄武曾獲准移除「生」小方塊並置中標題，並不授權其他入口刪字或移除標籤。按鈕文案與互動保持；圖片使用裝飾語義及 pointer-events:none，避免攔截操作。

至少涵蓋窄手機、一般手機及平板（本案曾用 320／390／768／1024px）。比較實際 bounding box；標題置中需量文字範圍，僅量容器可能漏掉內層 flex 對齊問題。人工看近照與鄰卡對照，確認上下左右都自然、角色清楚完整。入口可進入不代表後端生成或命理功能已全部通過。

參考已驗證實例：`app/music-entry.module.css`、`reports/beast-game/home-music-xuanwu-preview-2026-11-04.md`，以報告最新段落及即時 Git 狀態為準，前段是設計過程，不是全部有效規格。

提交發布遵守專案 `AGENTS.md` 與當次授權。只包含批准檔案，分開新卡預覽；測試失敗如實記錄，不擴修其他命理功能。任何既有命理檢查例外或朱雀 AI 圖片例外都不能由本技能泛化到下一輪。部署排隊不算成功；發布完成需核對 origin/main、部署終態、公開手機畫面與入口，最後執行 `git status --short --branch`，如實保留並報告其他未提交工作。

## 2026-11-05 定稿：原卡清晰、接地與觸碰引導

後續業主點名入口可依此方式製作；不自動批次修改其他卡。標題常駐，原圖等比，提示只在 hover（有滑鼠）、active 或 focus-visible 顯示，保留原連結與開啟流程。

- 讀取 computed style 檢查圖與祖先的 filter/opacity；首頁曾套 saturate(0.38)，須只在指定入口解除，不能以過度增艷補償。
- 以腳掌實際接觸面對齊提示上緣，不以圖片 bounding box 或石台邊框猜測。前景爪尖可搭進上緣，但不遮文字；圖片不攔截操作。
- 腳掌、爪尖、毛髮保留不透明；淡出只處理外圍場景與腳下石面，避免硬裁切或霧化爪尖。各角色須逐張核對，不照抄百分比。
- 背景石台承接腳掌，待機與提示顯示兩態皆不可懸空、雙層石台或出現人工橫線。
- 角色一律用既有正式原卡。只有業主明確批准背景生成才可補景，生成物僅為背景並記錄來源，不生成或替換角色。
- 驗收需含原卡對照、手機窄/一般與平板、待機/按住/鍵盤提示、原目的頁與文字不遮擋。保存實測範圍，未發布不得稱已上線。

業主追加偏好：點名下一張入口後，代理可依主題自行選擇合適的現有神獸並直接套用此規範，展示成果後依回饋微調，不再先詢問選獸。這不授權修改未點名入口。

八字牛金牛預覽教訓：背景明度不同會露出矩形內圖，先對齊背景明度，不能以擴大淡出犧牲牛角、耳尖或蹄部。每張原圖先定位角色最外輪廓，遮罩不透明範圍必須涵蓋它；尺寸模擬通過不等於視覺驗收完成，必須實際查看截圖後才報完成。

## 逐腳無縫接觸微調（紫微斗數業主定稿）
