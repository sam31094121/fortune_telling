## 🚀 快速開始

### 所需設備
```
✓ 手機（iPhone 12+ 或 Android 10+）
✓ 平板（iPad Air 2+ 或 Android 平板）
✓ 電腦（任何現代瀏覽器）
✓ Wi-Fi 連線（穩定網速）
✓ 測試用的佔位符 ID：test_2026_10_07
```

### 測試URL
```
開發環境：http://localhost:3000/ghost-asura/cross-device-monitor
生產環境：https://your-domain.com/ghost-asura/cross-device-monitor
API端點：POST /api/ghost-asura/validate-consistency
```

### 預計時間
- 🕐 手機驗證：15-20 分鐘
- 🕐 平板驗證：10-15 分鐘
- 🕐 電腦驗證：10 分鐘
- 🕐 **總計：45-60 分鐘**

## 🔧 環境準備

### 步驟 1：瀏覽器更新
確保使用最新版本：

| 設備 | 瀏覽器 | 最低版本 |
|------|--------|---------|
| iPhone | Safari | 15.0+ |
| iPhone | Chrome | 最新 |
| Android | Chrome | 最新 |
| Android | Firefox | 最新 |
| iPad | Safari | 15.0+ |
| 電腦 | Chrome | 最新 |
| 電腦 | Safari | 14.0+ |
| 電腦 | Firefox | 最新 |

### 步驟 2：清除快取
**iPhone/iPad：**
```
設定 → Safari → 清除瀏覽歷史記錄、網站資料
```

**Android：**
```
設定 → 應用程式 → Chrome → 儲存空間 → 清除資料
```

**電腦 Chrome：**
```
Ctrl+Shift+Delete → 選擇「所有時間」→ 清除
```

### 步驟 3：關閉VPN/代理
確保直接連線，無 VPN 或代理

### 步驟 4：測試網路速度
```
開啟 https://speedtest.net
確保下載速度 > 5 Mbps
```

## 📱 三端驗證流程

### 手機驗證（iPhone / Android）

#### Phase 1：頁面載入
```
1. 開啟 Safari / Chrome
2. 輸入測試 URL
3. 等待頁面完全載入（應 < 2 秒）

✓ 檢查點：
  □ 頁面載入無卡頓
  □ 標題「🔐 鬼魅阿修羅跨設備監控」清晰可見
  □ 無紅色錯誤提示
```

#### Phase 2：設備識別
```
頁面應顯示：「當前設備：📱 手機」

✓ 檢查點：
  □ 設備型別正確識別
  □ 視窗寬度顯示 < 768px
```

#### Phase 3：四欄顯示驗證
```
向下滑動找到「當前設備」卡片下方的統計區域

✓ 檢查點：
  □ 看到四個並排的欄位（年、月、日、時）
  ☐ 欄位寬度均勻分佈
  ☐ 文字不重疊、清晰可讀
  
如果只看到 2 欄：
  ⚠️ 請清除快取（見環境準備步驟 2）
```

#### Phase 4：水平滑動驗證
```
用手指左右滑動四欄區域

✓ 檢查點：
  ☐ 可以左右平滑滑動
  ☐ 滑動反應迅速（無延遲）
  ☐ iOS 使用 -webkit-overflow-scrolling 流暢滑動
  ☐ 滑動時四欄欄位不消失
  
滑動方式：
  → 向左滑：看到日、時欄位向左移動
  ← 向右滑：看到年、月欄位向右移動
```

#### Phase 5：垂直滑動驗證
```
用手指上下滑動整個頁面

✓ 檢查點：
  ☐ 上下滑動流暢
  ☐ 內容完整載入（無遺漏）
  ☐ 可以看到所有資料區塊
```

#### Phase 6：開始驗證
```
找到「開始驗證」按鈕，點擊

✓ 檢查點：
  ☐ 按鈕點擊無延遲
  ☐ 出現載入狀態（「驗證中...」）
  ☐ 約 1-2 秒後顯示結果

預期結果：
  ✅ PASSED：三端一致
  或
  ❌ FAILED：三端不一致（應不會出現）
```

#### Phase 7：檢視結果
```
頁面應顯示驗證結果卡片

✓ 檢查點：
  ☐ 看到 Hash 值（64 字符）
  ☐ 看到驗證指標
  ☐ 成功率應為 100%
  ☐ 平均回應時間顯示

記錄信息：
  📝 截圖或記下結果，供反饋使用
```

**手機驗證完成 ✓**

## 🔍 問題診斷

### 問題 1：只看到 2 欄而不是 4 欄

**症狀**：統計區域顯示 2x2 網格（2 欄 × 2 行）

**解決步驟**：
```
1. ✓ 清除瀏覽器快取（見環境準備）
2. ✓ 完全關閉並重新打開瀏覽器
3. ✓ 嘗試無痕模式（Incognito）
4. ✓ 確認瀏覽器是最新版本

仍未解決？
→ 拍照並報告（見反饋提交）
```

**技術細節**（開發者參考）：
```
應該看到的 CSS：
  grid-template-columns: repeat(4, minmax(140px, 1fr))

如果看到 repeat(2, ...)：
  → 快取未清除或代碼未更新
```

### 問題 2：無法左右滑動

**症狀**：四欄固定，無法滑動查看所有欄位

**解決步驟**：
```
1. ✓ 確認視窗寬度 < 768px（手機模式）
2. ✓ 用手指在欄位區域滑動（不是整頁滑動）
3. ✓ 嘗試長距離滑動（不是輕輕點擊）
4. ✓ 檢查手指是否觸發了其他操作

特定設備：
iOS：      需要 -webkit-overflow-scrolling: touch
Android：  內建支援，應正常工作
```

### 問題 3：驗證失敗或超時

**症狀**：點擊「開始驗證」後出現錯誤或長時間無回應

**解決步驟**：
```
1. ✓ 檢查網路連線（Wi-Fi 或 4G）
2. ✓ 刷新頁面並重試
3. ✓ 系統會自動重試 3 次
4. ✓ 等待 10 秒（預設超時時間）

檢查開發者工具：
  → F12 → Network → 查看請求狀態
  → 應看到 POST /api/ghost-asura/validate-consistency
  → 狀態應為 200（成功）
  
如果是 500 錯誤：
  → 後端異常，請報告
  
如果是超時：
  → 網路異常，重新嘗試
```

### 問題 4：Hash 值不一致（三端不同）

**症狀**：手機、平板、電腦顯示的 Hash 值不同

**解決步驟**：
```
1. ✓ 確認三端數據完全相同
2. ✓ 再驗證一次（快取可能延遲）
3. ✓ 檢查是否在驗證中間改變數據

預期行為：
  → 相同輸入 → 相同 Hash
  → 任何輸入改變 → Hash 改變
  
如果 Hash 意外不同：
  ⚠️ 這是 BUG，請立即報告（見反饋提交）
```

### 問題 5：頁面載入很慢

**症狀**：打開頁面需要 > 5 秒

**解決步驟**：
```
1. ✓ 檢查網速（speedtest.net）
2. ✓ 檢查設備是否有其他應用占用網路
3. ✓ 查看開發者工具 Network 標籤
   → 找出最慢的資源

性能目標：
  首頁載入：< 2 秒（4G）
  驗證回應：< 500ms（API）
  
如果遠超目標：
  → 報告詳細信息（見反饋提交）
```
