# 立體太極模型｜外站權威參考看板

建立：2026-09-20  
用途：先找可授權／權威參考，再優化組合成**自己的檔案素材**。  
本機卡片：`model-lab` → id `taiji` → `components/model-lab/models/taiji/`（TaijiModel + geometry）

## 本機既有

- 程序幾何球體太極（單位球、陰陽半球、魚眼點、接縫／外緣），對齊 MathWorld／Wikipedia 思路（見 registry note）。
- 參考圖：`/model-lab/ref/taiji/*.png`（對位用，非外站 mesh）。
