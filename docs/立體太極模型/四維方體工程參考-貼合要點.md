# 四維方體工程參考｜貼合要點（業主 2026-09-21）

來源：業主提供之「四維太極空間｜工程主版本」HTML／Canvas 程式（16 頂點／32 邊／六組旋轉平面）作工程參考。

## 必須達成

1. **內核**＝方形空心，**置中**。
2. **方形與外圓（太極殼）一比一緊貼**：無縫、方邊不冒出圓外。
3. 外殼太極剛好包住：外面看起來是緊貼完整的太極；**不露出內方**、**殼核之間不留空帶**。
4. 「任意視角仍見八點十二線方體」在本專案為 **Dynamic Local Frame**（觀察框架正規化），不宣稱是一般透視自然結果。

## 本機對應

- 外圓半徑 `FIT_RADIUS = 1`（與單位球太極殼一致）
- 內接正立方半邊 `1/√3`，八角到球心＝1
- 預設只畫外立方十二線；內核十字／往外冒出的方框關閉
