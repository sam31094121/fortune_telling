# 3D 工作室・四維幾何的外部權威來源與交叉比對

立體太極裡的「四角形空間」「四角形多重宇宙」不是自己編的形狀，是正八胞體（tesseract）的投影。
這份檔案記下外部權威資料、我們實際生成的數值，以及兩邊怎麼對上的。**數值全部由程式算出來，不手填。**

## 一、外部權威來源

| 來源 | 內容 | 用在哪裡 |
|---|---|---|
| [Wolfram MathWorld — Tesseract](https://mathworld.wolfram.com/Tesseract.html) | 16 頂點、32 邊、24 個正方形面、8 個立方單元；Schläfli 符號 {4,3,3}；頂點座標 (±1,±1,±1,±1) | 單元的頂點與邊、面數、單元數 |
| [Wikipedia — Tesseract](https://en.wikipedia.org/wiki/Tesseract) | 同上；並說明頂點優先（沿體對角線）的平行投影 | 等長投影的依據 |
| [Wikipedia — Rhombic dodecahedron](https://en.wikipedia.org/wiki/Rhombic_dodecahedron) | 正八胞體沿體對角線的平行投影外殼＝菱形十二面體：12 個全等菱形面、24 條邊、14 個頂點分兩種；8 個立方單元投影成 8 個平行六面體 | 等長投影的外殼對照 |

外部條款與版本未經人工逐項確認者，狀態一律「待查核」；此處只取「幾何事實」這類可獨立驗算的內容，
不取需要授權的圖檔或文字。

## 二、我們算出來的值（程式輸出，非手填）

| 項目 | 權威值 | 本站算出 | 對得上 |
|---|---|---|---|
| 頂點數 | 16 | 16 | ✓ |
| 邊數 | 32 | 32 | ✓ |
| 正方形面數 | 24 | 24 | ✓ |
| 立方單元數 | 8 | 8 | ✓ |
| 頂點座標 | (±1,±1,±1,±1) | 全部為 ±1 | ✓ |
| 尤拉特徵（四維） | 16 − 32 + 24 − 8 = 0 | 0 | ✓ |
| 等長投影邊長 | 全部相等 | 32 條全部 = √3 = 1.732050807569 | ✓ |
| 投影外殼頂點 | 14 個、分兩種 | 14 個：6 個半徑 2、8 個半徑 √3；另兩個頂點疊在投影軸中心 | ✓ |

精度：以上比對全部以 **1e-12** 為容許誤差（比億萬分之一還嚴）。
守門：`npm run test:model-lab-equal-edge`、`npm run test:model-lab-multiverse`、`npm run test:taiji-4d-cells`（皆在推送閘內）。

## 三、放進太極的尺寸（與太極本體交叉比對）

| 項目 | 值 | 怎麼來的 |
|---|---|---|
| 內壁格距 | 0.6 | 同事的 `squareCavity`：`CAVITY_PITCH = ENTRANCE_SCALE` |
| 內壁線寬 | 0.0036 | `BEAM × ENTRANCE_SCALE` |
| 四維單元放進太極後的格距／線寬 | 0.6／0.0036 | `PROJECTION.taijiScale × CELL_SPACING`、同比例縮放——與內壁 1:1 |
| 球內完整格子數 | 7（中心＋六面） | 八個角都在半徑 0.995 內才算完整格 |
| 七格併起來的線 | 84 − 24 = 60 條 | 與內壁 60 條格線「完全同一組」，不多不少，所以沒有縫 |
| 七格併起來的面 | 42 − 6 = 36 個 | 每個面仍是同樣大小的正方形 |
| 一顆內接正立方 | 邊長 2/√3 ≈ 1.154701 | 八個角到球心距離剛好 1（貼住球面），半邊 0.5774 < 切面 0.7071，切口切不到 |

## 四、老實話（不得省略）

- 透視投影下「外立方大、內立方小、連接邊斜」是**視覺**，不是形狀差異；四維裡 32 條邊等長、24 個面都是正方形。
- 等長投影能讓 32 條邊在畫面上一樣長，但四維的直角壓到三維會變成菱形角——任何三維投影都躲不掉，想看直角要回去看單一個立方單元。
- 多重宇宙是把同一個單元重複鋪開的**視覺概念**，不是數學上的四維空間填充。
