# 神獸戰鬥儀式：五元素靜態教學

入口：成長中心 → 我的神獸收藏 → 收藏押注決鬥。

- 前端展示後端產生的五元素關係表、本場雙方元素、關係、倍率、勝負與逐回合戰報。
- `/api/beast-game/elements` 提供知識表；`stake-duel` 使用既有 interactive 引擎運算並回傳 elementLesson。前端只有型別引用，不載入戰鬥運算。
- 相剋倍率沿用元素核心；相生目前只教學、不新增加攻／回血／能量。界面明確說明這一限制。
- 每場結果停留到重新選牌；詳細戰報可自行展開。押注區取消獎勵閃爍與平滑自動捲動。
- 本次適用成長中心的收藏決鬥，不代表其他工程師正在修改的所有戰場演出已改為靜態。

驗證：五種相生／相剋關係、25種攻守配對倍率、API 真實後端戰報、瀏覽器靜態關係表載入；未用客戶收藏實際下注。
