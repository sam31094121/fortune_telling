# 成長收藏押注：規則與驗收

更新：2026-09-05。

## 客戶看到的規則

- 出戰可使用六十張試用牌庫；押注只能從成長中心目前持有的卡選一張。
- 勝利保留自己的押注卡，增加對手押的卡一張。敗北扣自己的押注副本一張；有同名多張時顯示剩餘張數。平手原卡退回。
- 結果並列卡圖、卡名、「獲得 ＋1」或「輸掉 −1」，直接連到成長中心收藏格。獲得和沒收都留紀錄。
- 成長中心顯示實際持有的總張數、同名張數及成長／對戰來源。羈絆解鎖成就另外標示，不把歷史解鎖數誤當目前持有數。

## 存檔與公平性界線

`tdh_beast_collection_v1` 沿用原存檔，保留既有對戰卡副本，補入已完成探索與每日任務對應的成長獎勵。`granted` 保留已領取標記，輸掉後重新開頁不會補發；每一張實例有穩定 ID。舊版曾記錄卻未實際扣掉的卡無法可靠追溯，不追加追扣。

押注前在 Web Locks 的同來源鎖內讀取最新收藏並預留實際副本。沒有卡、資料損壞、儲存失敗、其他分頁佔用，均不送出新對戰。沒有安全鎖能力的瀏覽器暫停押注。跨分頁事件與成長事件更新畫面。

勝負與獎品由現有遊戲核心／API 決定。本機帳本只執行移交。對手押注在執行戰鬥前固定；對戰請求不自動以新亂數重試。收到有效戰果先寫恢復日誌與結算，再播動畫；略過、重播不再移交卡片。每場收據獨立去重，不隨最近六十筆可見歷史一起裁切。

沒有收到戰果的連線中斷不扣卡。收到戰果但保存失敗時禁止宣稱已領取／已沒收，封鎖下一場，提供重試；重開頁從恢復日誌繼續。日誌與帳本均無法寫入時，關閉頁面可能無法恢復該戰果，不宣稱資料永久可靠。

這是匿名、同瀏覽器保存的單人電腦對戰。沒有登入帳號或伺服器權威收藏；使用者自行竄改／清除瀏覽器資料不在防作弊保證內。API 不能獨立驗證本機所有權，不能把這套機制用於真實金錢、玩家交易或多人競技資產；那些用途需要額外的伺服器帳本與授權。

## 驗收

`npm run test:beast-stake` 同時執行核心押注守門與 25 項收藏／收據回歸：成長卡真正扣除、重開不補回、同名副本、無卡阻擋、勝／敗／平、重播、雙分頁互斥、儲存故障、日誌恢復、舊卡遷移、損壞資料保護、歷史裁切後去重，以及結果元件實際 HTML 文案。

健康檢查沿用同一命令，並包含核心公平性、千局抽樣及 API 限制。手機畫面以瀏覽器尺寸核對押注引導、收藏張數與卡名，未使用客戶收藏進行實際輸卡；不是 iOS／Android 真機驗收。
