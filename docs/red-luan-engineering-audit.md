# 紅鸞年度工程稽核

此工具僅供工程師在本機核對規則；沒有客戶入口、不寫入客戶資料，也不產生關係事件預測。

```powershell
npm run audit:red-luan -- --birth 1990-05-12 --gender female --from 2026 --to 2030
```

已知出生時辰時，可加上紫微本命夫妻宮與生辰起卦核對：

```powershell
npm run audit:red-luan -- --birth 1990-05-12 --gender female --hour 午 --from 2026 --to 2030 --iching-birth --json
```

輸出內容：

- 八字本命現位、紅鸞／天喜／桃花年度命中、規則版本與來源。
- 紫微本命夫妻宮與三方四正的可用狀態；未知時辰時保持不可用，不預設時辰。
- 易經僅在指定 `--iching-birth` 且已知時辰時以梅花易數生辰起卦；否則清楚列為未要求或資料不足。

邊界：只列年度層級。月、日、時的紅鸞精度尚未在專案內選定可追溯規則，因此工具不輸出此類結論。
