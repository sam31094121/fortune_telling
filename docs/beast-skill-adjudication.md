# 戰鬥技能判決檔案

## 適用入口
成長中心收藏決鬥 `/api/beast-game/stake-duel`。

## 不收個人資料
判決不接三合一，不要求姓名、生日、出生時辰。三合一屬其他產品功能，不是戰鬥資格或勝負依據。

## 判決流程
1. 依實際收藏選擇押注卡，第一張出戰。
2. 後端共用戰鬥核心計算技能、能量、冷卻、元素倍率、防禦、護盾及生命；雙方用相同規則。
3. 終局後核對生命範圍與擊倒標記；勝方必須與全部擊倒狀態相符。雙方仍存活時，只能在80回合上限後判平手。
4. 未完成、生命矛盾、勝負矛盾一律拒絕結算。
5. 前端靜態顯示判決理由、剩餘生命、完成回合與原始戰報，不自行改判。
6. 收藏帳本再核對押注副本與收據，避免重複扣牌／發獎。

規則識別：`beast-adjudication-v1`，同時回傳實際戰鬥核心版本。
這是驗證既有規則一致性，不宣稱所有卡片勝率相同。收藏仍為瀏覽器本機保存，尚無伺服器帳號持有驗證。

驗證：50場既有引擎終局；未完成、偽造勝負、負生命、擊倒標記矛盾、未達上限的平手均拒絕。
