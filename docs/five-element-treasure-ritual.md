# 五元素寶珠統一規格

適用於首頁八張功能卡片所到達的功能，**僅在該功能實際呈現五元素寶珠／解封流程時**。

- 固定顯示五顆：空、風、水、火、地；初始都為封印狀態。
- 五行計算永遠保留金、木、水、火、土；唯一前台映射鎖定在 `lib/five-element-orb-map.ts`：木→風、火→火、土→地、金→空、水→水。所有頁面必須呼叫此來源，禁止頁內覆寫。
- 上方主珠必須由該功能既有的正統計算結果決定，不可在介面端重新猜測或改算。
- 僅主珠可由使用者啟動；流程固定為 0、3、6、9、12 秒，並在結束時提供清楚的完成文字。符咒化灰動畫只在此使用者操作後播放。
- 主珠完成後必須顯示「還原封印」；此操作會清除完成態、恢復最初封咒，並可再次執行完整 12 秒流程。四顆對照珠在任何狀態都維持封印。
- 下方四顆只能作封印狀態的對照展示，沒有點擊或解封行為。
- 手機與桌面使用同一套資料與流程；點擊只在使用者主動操作後開始，WebGL 預覽以低 DPR 顯示，避免行動裝置因同時預覽而過載。
- `prefers-reduced-motion` 時仍依同一個 12 秒狀態流程，並以文字與完成態提供可辨識回饋，不依賴動畫才看得出完成。
- 所有新實作使用 `WaterTreasureOrb` 呈現寶珠，並使用 `useElementTreasureRitual` 管理主珠流程；不得自行複製計時或改用不同的封印資產。
