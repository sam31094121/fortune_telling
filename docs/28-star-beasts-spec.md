# 神獸卡圖規格與套版手冊

版本：v1.0  
用途：後續神獸卡圖的固定尺寸、底板與生成操作手冊。  
狀態：已確認。神獸個別設定、文案與世界觀規格由後續需求另行提供。

## 1. 圖像大小規格

- 卡片比例：`275:480`
- 方向：直式
- 最終交付尺寸：`275 x 480 px`
- 工作母版尺寸：`950 x 1656 px`
- 格式：PNG
- 圖中不放名稱、文字、英文、Logo 或浮水印

製作時以 `950 x 1656 px` 母版工作；正式上架前再依需求輸出為 `275 x 480 px`。

## 3. 已驗證的正確生成方法

### 3.1 核心原則

每一張成品都必須以指定季節底板作為「編修目標」。季節由該神獸的新規格指定；沒有指定時，先確認後再生成。

不要用文字重新生成一整張卡牌，也不要只把神獸獨立圖硬疊到底板上。前者會讓卡框與背景飄移；後者可能出現假的透明棋盤格或不自然的光影。

正確方法是：

```text
固定季節底板 + 以底板做精準編修 + 在中央留白加入一隻神獸 = 最終卡圖
```

### 3.2 每張卡的操作流程

1. 選擇指定季節的工作母版，先確認該底板為唯一視覺來源。
2. 將底板作為圖片編修的輸入圖，而不是只當文字風格參考。
3. 在提示詞中明確描述該神獸的物種、體態、氣質、四象部位本源與專屬能量。
4. 明確要求神獸只填入中央留白：頭部在上半部、主體落在中央、下半身自然融入既有雲海。
5. 用「不得改動」條款鎖住卡框、四角飾紋、星盤、雷電／天象、雲海與外側黑邊。
6. 檢查成品後，以新版檔名存入 `public/star-beasts/`；底板永遠不覆寫。

### 3.3 已驗證結論

**底板編修生成**比「完整卡牌重新生成」或「透明神獸硬合成」更穩定。新系列一律使用本章流程，並以春夏秋冬母版為準。

## 4. 可重複使用的提示詞模板

使用時先載入指定季節的工作母版，並把底板標為「唯一編修目標」。再將以下 `{}` 中的內容替換成該神獸的新規格。

```text
用途：二十八星宿神獸系列的完成卡圖。
輸入圖片：此圖片是唯一且鎖定的「{春／夏／秋／冬}」卡牌底板。

主要要求：只在卡牌中央留白加入一隻「{神獸名稱}」。
牠的個別設定：{使用者提供的本源、部位或世界觀規格}。
物種必須清楚是「{動物本體}」，不可被畫成其他動物。

外型與姿態：{體態、比例、頭部、四肢、姿勢、輪廓差異}。
氣質：{性格、位階、威嚴感或靈性}。
專屬能量：{星印、光源、火／水／雷／風等效果}。

位置：神獸填入既有中央留白；頭部位於上半部；
身體完整可辨識；下半身自然融入既有底部雲海；
保留圓形星盤外圈可見。

風格關鍵詞
神獸卡牌、精緻厚塗、收藏卡插畫、星光符紋、金色細線、雲霧靈氣、莊嚴神性、高級神秘感、乾淨輪廓風格基調
整套圖應呈現「傳統 + 現代收藏卡」的視覺感。

不得改動：外側金色卡框、四角飾紋、黑色外邊、
上方與下方中央飾件、圓形星盤、既有天象、星空與雲海構圖。

避免：文字、標題、中文、英文、Logo、浮水印、UI、
其他生物、重複頭部、多餘肢體、錯誤物種、過度遮住卡框。
```

## 5. 提示詞撰寫規則

- 必須先說清楚「牠是什麼動物」，再說四象部位如何化生到牠身上。
- 必須寫出與同組神獸不同的輪廓，不能只替換名稱與顏色。
- 不要只寫「霸氣」或「神聖」；改為可畫出的描述，例如「寬肩厚頸、正面俯視、厚重胸甲」。
- 每張只設一個最亮焦點，例如亢金龍的咽喉王令星印。
- 色彩、雲霧與能量效果需服從指定季節底板，不能蓋過底板的主色與景物。
- 每次只生成一張；確認物種、姿勢與位階正確後才繼續下一張。

## 6. 完成前檢查

- 是否使用了指定季節的工作母版。
- 金色卡框、四角、天象裝飾與既有季節景物是否仍完整。
- 神獸是否一眼可辨識為指定物種。
- 該神獸是否和同組已完成者有清楚的輪廓與位階差異。
- 主體是否置於中央，且沒有遮住主要卡框。
- 最亮焦點是否符合該神獸的新規格。
- 是否沒有文字、亂碼、Logo、浮水印、UI 或多餘生物。
- 是否輸出為 PNG，並可安全縮放為 `275 x 480 px`。
