## 🆘 常見問題速查

| 問題 | 解決方案 |
|------|---------|
| 只看到 2 欄 | 清除快取 + 重新打開瀏覽器 |
| 無法左右滑動 | 確認手機寬度 < 768px，用手指滑動四欄區域 |
| Hash 值不同 | 重新驗證（快取延遲），檢查數據是否改變 |
| 驗證超時 | 檢查網速，系統會自動重試 3 次 |
| 出現紅色錯誤 | F12 檢查 Console，截圖並報告 |
