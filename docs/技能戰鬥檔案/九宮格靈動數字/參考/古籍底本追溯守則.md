# 古籍底本追溯守則（洛書九宮古籍版用）

建立日期：2026-10-21。性質：**作業守則，不是來源**。下面「候選版本」是我（Claude）憑記憶列出的方向，**一律視為待核對**，在拿到書目紀錄或影像之前，不得寫進來源登記表當成事實。

## 一、什麼才算「可追溯底本」（四樣缺一不可）

1. **哪一本**：書名、版本（例：某某叢書本、某某年刻本）、撰者／注者／刻印者。
2. **在哪裡**：卷、篇、頁（或葉）；收藏單位與典藏號或書目連結。
3. **文字核對過**：我們引的每一句，在該版本影像或授權文本裡逐字找到；異體字、斷句另行註記，不改字。
4. **授權明確**：影像或文本的授權條款可查，允許本站引用短句並標出處。

少一樣，來源登記表就維持「版本不可追溯」，狀態留在待驗證資料池（`lib/iching-source-gate.ts` 會自己擋，不得手改）。

## 三、不採用當來源的東西

- 百科、新聞網站、社群貼文、AI 整理的彙整文字：一律 D 級，只能當線索。
- 電子文本網站頁面標不出底本的（例：維基文庫這幾頁只有修訂編號）：只能當「文字參考」，不是底本。
- 禁止爬取的網站（例：中國哲學書電子化計劃）：不繞過，要用請走官方授權管道。

## 三之一、業主貼的彙整文字，逐點查驗（2026-10-21）

- 《周易折中》是清代李光地等人奉敕所編，不是朱熹的書；朱熹的是《周易本義》與《易學啟蒙》。
- 《尚書·洪範》正文有「天乃錫禹洪範九疇」，但沒有寫洛書或神龜，兩者是後來才連在一起的說法。
- 《大戴禮記》〈明堂〉的原文是「二九四七五三六一八」，與《數術記遺》口訣排出的 4 9 2／3 5 7／8 1 6 是左右鏡像，不是同一個排法。
- 「官方」「最高公權力」「孔子及弟子所著」等說法，學界有爭議，不得寫成事實。

## 四、核對流程（每找到一個底本就走一遍）

1. 取得書目紀錄（書名、版本、卷冊、典藏號、授權條款）。
2. 把我們檔案裡引自該書的每一句，逐字比對影像或授權文本；不一致的列出來，由業主決定，不自動改字。
3. 在 `docs/技能戰鬥檔案/易經/來源登記.json` 更新該來源的 `edition`、`locator`、`license_terms`，移除「待查核」字樣。
4. 跑 `npm run test:iching-sources` 與 `npm run test:nine-grid`；狀態由閘門算。
5. 全部四筆都通過，`C-LUOSHU-JIUGONG` 才可能離開待驗證資料池。

## 五、話術要有說服力，靠的是這三件事

- **每一句附出處**：書名、篇章、版本，客人點開就看得到。
- **誠實講限制**：例如「說卦傳沒有寫坤的方位」，講出來比硬補更有公信力。
- **不誇大**：不寫「最權威」「官方」「已證實」，只寫「古籍裡這樣記載」。
