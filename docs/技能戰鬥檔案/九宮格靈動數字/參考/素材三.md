## 素材自述的概念（摘要，未核對）

- 「八十一靈動數」源於日本熊崎健翁的理論；以康熙字典筆劃算姓名五格（天、人、地、外、總），再對應 1 至 81 的數理。
- 五格算法（素材自述）：天格＝單姓加 1、複姓相加；人格＝姓＋名第一字；地格＝名中字＋尾字（單名加 1）；外格＝總格減人格（或尾字加 1）；總格＝全名筆劃總和（超過 81 減 81 的倍數）。

## 與本站既有檔案的關係

- 五格算法與 81 數理本站已另有檔案：`docs/技能戰鬥檔案/姓名學/姓名學.json`（來源登記 `C-NAMEOLOGY-GRIDS`），不在本檔重複建立第二套。
- 這份素材屬於「姓名學靈動數」，和「生日九宮格（生命靈數）」「洛書九宮（古籍版）」是**不同的東西**；放在這裡只是方便隨時取用與對照，不併入九宮格的算法。
