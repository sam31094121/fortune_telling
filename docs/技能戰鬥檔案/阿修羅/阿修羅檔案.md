## ⚙️ 核心演算法

### 入口函式

```typescript

 * 單項轉譯 — 前端調用
 */
export function translateToAsuraName(
  originalName: string,

 * 批量轉譯 — 含去重防衝突
 */

  names: string[],

```

### 邏輯流程

1. **17 項正式名稱？** → FIXED_ASURA_MAP 直接返回
2. **不在 17 項？** → classifyAsuraFamily(originalName)
3. **決定語系家族** → ASURA_FAMILIES[family]
4. **穩定生成** → stableHash(originalName + ruleVersion)
5. **組合詞彙** → prefixes[seed] + suffixes[seed % suffixes.length]
6. **去重** → usedNames Set
7. **返回阿修羅名稱**

### 穩定 Hash — 無隨機性

```typescript
export function stableHash(input: string): number {
  let hash = 2166136261;
  for (let i = 0; i < input.length; i++) {
    hash ^= input.charCodeAt(i);
    hash += (hash << 1) + (hash << 4) + (hash << 7) + 
            (hash << 8) + (hash << 24);
  }
  return hash >>> 0;
}
```

**特性：**
- ✅ 同輸入永遠同輸出
- ✅ 不含 Math.random()
- ✅ 每次執行結果完全確定
- ✅ 可用於版本控制（ruleVersion）
