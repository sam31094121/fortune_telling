# 《易經》公信力話術｜大數據・公信力・權威性

> 業主定案（2026-09-16）：**大數據、公信力、權威性的話術寫入檔案；後端運算、交叉性比對，前端只負責視覺感官；心理學概念全部列為技能檔案，口令《易經》。**
> 口令順序不變：① 填寫資料 → 八字命盤 ② 紫微斗數命盤 ③ 易經心理學、洋蔥心理學、權威心理學大數據。
> 來源規則：`易經/來源治理.md`；融會貫通總覽：`易經/三核心融會貫通.md`。

## 二、狀態 → 客戶說法（後端自動套用）

| 閘門狀態 | 客戶看到 | 意思 |
|---|---|---|
| VERIFIED | 已通過交叉比對 | 權威檔＋大數據＋交叉 ≥ 3、授權 PASS、衝突 0 |
| CONFLICT | 各家來源說法不一，僅作傳統參考 | 有重大衝突未解 |
| PENDING_POOL | 仍在查證中，僅作自我反思參考 | 來源、授權或版本尚未齊全 |

目前（2026-09-16）只有兩項 VERIFIED：**八字四柱排盤正確性**、**神獸卡對手智能**。其餘一律不得說「已驗證」。

## 三、核准句子（`APPROVED_PHRASES`）

| 用途 | 句子 |
|---|---|
| 資料範圍 | 本報告依你的生日、時辰與姓名，用固定規則在後端計算；同樣資料每次結果都一樣。這不是拿很多人的資料統計出來的排名，也不是準確率。 |
| 心理學定位 | 心理學名詞只用來引導自我反思，名詞對照 APA 心理學辭典，並以 PubMed、APA PsycInfo 等研究資料庫查證；不做診斷，也不預測未來。 |
| 三核心上限 | 八字、紫微斗數、易經是傳統與文化詮釋，不是科學證實的預測。 |
| 交叉比對 | 八字與紫微斗數的年、月、日、時四柱在後端逐字核對，一致才往下解讀。 |

「大數據」只能指**真的存在的權威資料庫**（PubMed 4,000 萬筆以上書目、APA PsycInfo、香港天文台 1901–2100 曆表、交通部中央氣象署日曆資料表），並說清楚是「查證名詞與曆法」，不是「拿很多人的命盤統計」。

## 四、不准說（`BANNED_CLAIMS`，守門會掃前端）

| 句型 | 為什麼不行 | 已改成 |
|---|---|---|
| 「大數據將…」「大數據 易經運算終端」 | 本站沒有人群樣本（`sampleSize 0`、`bigDataInsights` 空） | 「🧬 三核心 易經運算終端」 |
| 「聲波諧振」 | 沒有任何來源支持 | 「後端依正體字典筆畫計算五格，再與生日、時辰交叉比對」 |
| 「判定準確度」 | 分數評的是資料完整度與規則覆蓋，不是預測準確 | 「資料完整度核對」 |
| 「加深每週判定的精準度」 | 沒有驗證顯示回訪會更準 | 「每週紀錄越完整，易經的回顧就越貼近你真實走過的路」 |
| 「科學證實命…」「準確率高達」 | 對照研究未發現命理有超越機率的預測力 | 用〈三〉的三核心上限 |

否定句（例：「命理不做準確率宣稱」）可以用；程式註解裡記錄舊說法為何錯也可以（客戶看不到）。

## 五、前端視覺感官心理學（前端唯一的職責；2026-09-16 上網查證）

### 有標準或重複驗證支持（當硬規則）

| # | 規則 | 依據 |
|---|---|---|
| 1 | 內文對比至少 4.5:1、大字 3:1；長輩與暗色模式再拉高 | WCAG 2.2 §1.4.3；Owsley 2011（老年對比敏感度下降、低光更差） |
| 2 | 放大到 200% 不失內容；不得禁止縮放；行高 1.5 倍、段距 2 倍不破版 | WCAG 2.2 §1.4.4、§1.4.12 |
| 3 | 點擊目標至少 24×24 CSS px；主要按鈕（開始排盤、下一步、送出）44×44 以上 | WCAG 2.2 §2.5.8／§2.5.5；Fitts 1954 |
| 4 | 尊重 `prefers-reduced-motion`：翻牌、粒子、視差可關；動畫不得是唯一資訊來源 | WCAG 2.3.3、技術 C39；MDN |
| 5 | 閱讀區不放裝飾雜訊；老年人視覺處理在雜亂與高注意負荷下更慢 | Owsley 2011 |
| 6 | 每一步只給少量選項（約 4 組）；生辰資料留在畫面上，不要客人記前一頁 | Cowan 2001（取代 Miller 7±2）；Sweller 1988；Hick–Hyman |
| 7 | 用鄰近與共同底色分組（四柱、宮位、卦爻），少用框線 | Wertheimer 1923；Wagemans 等 2012 |

### 證據較弱（當指引，不當硬規則）

| # | 規則 | 依據與限制 |
|---|---|---|
| 8 | 第一眼質感、零錯字、看得到真實來源，影響可信度 | Lindgaard 2006（50 毫秒判斷視覺吸引力）；Fogg 2003（「設計外觀」被提及最多，自願樣本）；美感－易用效應（Kurosu 1995、Tractinsky 2000）——不能取代真正好用 |
| 9 | 不宣稱顏色的心理功效（紅色招財、藍色安定）；顏色不得是唯一表意 | Elliot & Maier 2014：色彩心理學「仍在起步」，多項效應未重現 |
| 10 | 標出最後審閱日期、來源容易查證 | Stanford 網站可信度指引（2004，年代久） |

「米其林精神」的前端解讀：**把後端算好、查證好的內容，用看得清、點得到、不暈眩、不誇大的方式端上桌**；可信度來自清楚與誠實，不是來自「大數據」「準確率」這類字眼。
