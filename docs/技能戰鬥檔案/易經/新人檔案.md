# 《易經》新人檔案｜對手智能

> 這是**易經對手智能**的新人導讀。之後維護以本目錄正式檔為準。

## 口令

說「易經」＝打開本目錄與正式檔 `易經/易經.json`，並對照制度章 `docs/beast-game-skill.md`〈二十四、「易經」檔案〉。

| 檔案 | 用途 |

## 新人必知

1. **只變聰明，不改傷害公式**——雙方同一套 orbs／rage／相生後備／`RAGE_TIERS`。
2. **免費三卡（UI「簡單」入口）開戰送 `difficulty: NORMAL`**——變聰明基線；舊存檔缺 `difficulty` 仍走 EASY。
3. **玩家自動連擊固定 EASY**（業主定調）。
4. **本機大數據**（`data/beast-turn-accounts`）：對手技能率約 33～34%，暴怒僅約 1%——暴怒政策必須讓對手在雙珠／血量壓力時會放 RAGE。

## 來源治理（2026-09-15 業主鐵律）

凡有「易經」兩個字，都要有**交叉比對的來源、權威性的檔案、大數據的來源**；易經洋蔥心理學一樣。

- 規格：`易經/來源治理.md`（五級來源閘門、SOURCE_PERMISSION_GATE、三方交叉、通過標準、待驗證資料池）
- 登記表：`易經/來源登記.json`——狀態由 `lib/iching-source-gate.ts` 算，不得手填 VERIFIED
- 守門：`npm run test:iching-sources`（在推送閘內）；新增名稱含 iching／易經 的檔案沒登記就擋
- 外部書目與網站條款未經人工確認，一律「待查核」

## 後端運算、前端只顯示（2026-09-15 業主定調）

後端運算、前端只顯示（米其林分工）：後端負責品質穩定與服務——技能、易經判斷、勝負、押注結算、來源治理全部在後端算完再送出；前端負責視覺感官與價值——把結果與有權威來源的易經洋蔥心理學好好呈現，不做任何運算。

- 困難戰場：`POST /api/beast-game/battlefield`（START／ACTION／AUTO）。易經出手、首領反制、勝負、易經技術判斷、押注獎勵都在後端；每回合回傳簽名戰局票，前端帶著票送下一招。
- 戰局票擋得住竄改血量、勝負、押注張數；擋不住拿舊票重出一招（收藏帳本本在客人瀏覽器，不假裝做到）。
- 簡單：自動下一招走 turns API `AUTO_STEP`。
- 守門：`npm run test:beast-backend-only`——網頁端元件不得呼叫 advance／chooseAI／newMatch／judgeVictorySkill／resolveStake 等運算。
- 第二階段完成：可按的招與暴怒判斷由後端 `battleViewFor` 送來（`view` 欄位），元件只照印。
- 第三階段 3A 完成：困難頁開局的洗牌、發牌、易經自動佈陣由困難戰場 API 的 DEAL 在後端做，回傳簽名牌桌票；開戰（START）核對玩家只用發到手上的卡，易經陣容一律採用牌桌票裡後端排好的（前端送什麼都不採信）。
- 第三階段 3B 待辦：相剋與戰力分析（combatGuideFor／describeMatchup／explainOutcome／elementPercent／elementGuideRows／elementMultiplier，在 BattleArena、BattleCardGuide、BattlePanel、BeastCardTile、ElementMatchupGuide、MatchupSummary）；演出規劃（planTierPresentation／planFusionPresentation）只決定播哪段動畫與音效，屬前端視覺感官，不列入後端化。
