## 口令

說「易經」＝打開本目錄與正式檔 `易經/易經.json`，並對照制度章 `docs/beast-game-skill.md`〈二十四、「易經」檔案〉。

| 檔案 | 用途 |

## 新人必知

1. **只變聰明，不改傷害公式**——雙方同一套 orbs／rage／相生後備／`RAGE_TIERS`。
2. **免費三卡（UI「簡單」入口）開戰送 `difficulty: NORMAL`**——變聰明基線；舊存檔缺 `difficulty` 仍走 EASY。
3. **玩家自動連擊固定 EASY**（業主定調）。
4. **本機大數據**（`data/beast-turn-accounts`）：對手技能率約 33～34%，暴怒僅約 1%——暴怒政策必須讓對手在雙珠／血量壓力時會放 RAGE。
