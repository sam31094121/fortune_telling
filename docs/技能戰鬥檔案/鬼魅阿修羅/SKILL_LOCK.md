## 鐵律一覽

### 1. 唯一性鐵律
```
【唯一檔案】

鬼魅阿修羅相關的所有技能檔案、規則、話術庫
只有一份：本檔案。

禁止：
❌ 另開第二份鬼魅阿修羅檔案
❌ 建立第二套性別表達核心
❌ 分散式改造
❌ 側身規避本鐵律

違反即不准推送。
```

---

### 2. 應用範圍鐵律
```
【三張卡專用】

過去卡：人格形成因素 + 剛柔判定 + 話術個人化
現在卡：當下反應模式 + 溝通偏好 + 直接度微調
未來卡：趨勢放大預測 + 警告切口 + 收尾銳度

八字核心、紫微排盤、易經運算：
✅ 允許（共用後端）

八字卡、紫微卡、其他鬼魅阿修羅區塊：
❌ 禁止順手修改（違反技能檔案專用）

只動三張卡。其他一切禁止。
```

### 3. 數據分層鐵律
```
【客戶自填 vs 後端交叉】

DeclaredSex（客戶自填）
  ├─ MALE
  ├─ FEMALE
  ├─ OTHER
  └─ UNSPECIFIED

ExpressionProfile（後端交叉驗證）
  ├─ OUTER_HARD_INNER_SOFT
  ├─ OUTER_SOFT_INNER_HARD
  ├─ HARD
  ├─ SOFT
  ├─ BALANCED
  └─ MIXED

【不得混用】

性別刻板印象完全禁止：
❌ 男性一定硬
❌ 女性一定柔
❌ 跳過人格直接性別下結論

違反即編譯擋下。
```

---

### 4. 後端 vs 前端分工鐵律
```
【米其林分工原則】

後端（lib/asura/ghost-asura-gender-expression-skill.ts）
  ✅ 讀取客戶性別
  ✅ 讀取已驗證人格
  ✅ 判斷剛柔表達
  ✅ 判斷內外反差
  ✅ 選擇阿修羅口氣
  ✅ 生成個人化話術
  ✅ 通過 lintAsuraVoice + sanitizeZiweiOutput

前端（features/ghost-asura/）
  ✅ 顯示話術
  ❌ 不做任何運算
  ❌ 不讀命理術語
  ❌ 不自己判斷人格
  ❌ 不改寫輸出

後端送什麼，前端照印。
```

---

### 5. 命理術語封鎖鐵律
```
【前端絕對禁止顯示】

七殺、武曲、貪狼、破軍、巨門、紫微、天府、太陰…
命宮、父母宮、福德宮…
廟旺落陷、四化、天干地支…
任何紫微術語
任何八字十神名稱
任何易經卦象原始名稱

前端看到的只有：
「這個人外面硬、裡面柔。」
不是：
「你是外剛內柔型。」

違反即推送擋下。
```

---

### 6. 性別認同保護鐵律
```
【絕對禁止推斷性別認同】

禁止：
❌ 由命盤推斷客戶性別認同
❌ 假設客戶同性別即同表達
❌ 說「你這個性別應該……」
❌ 暗示性別轉換需求

允許：
✅ 讀客戶自填的性別
✅ 根據人格判斷表達方式
✅ 「你外面硬，裡面敏感。」（描述，不判斷）

違反即編譯擋下。
```

---

### 7. 話術質量鐵律
```
【所有輸出必須通過三層檢驗】

第一層：lintAsuraVoice
  ├─ 分句 ≤ 16 字
  ├─ 零驚嘆號
  ├─ 零發問
  └─ 零認同助詞

第二層：sanitizeZiweiOutput
  └─ 48 項術語過濾

第三層：lintGenderExpressionOutput
  ├─ 性別刻板檢查
  ├─ 分類念誦檢查（「你屬於 X 型」禁止）
  └─ 禁止模式掃描

三層全過才能上線。

違反即推送擋下。
```

---

### 8. 證據強度鐵律
```
【證據等級決定深度】

evidenceLevel 1：輕碰
  └─ 直接度 50%、情感深度 50%

evidenceLevel 2：有支撐
  └─ 直接度 75%、情感深度 75%

evidenceLevel 3：清楚
  └─ 直接度 100%、情感深度 100%

evidenceLevel 4：極限清楚
  └─ 直接度 100%、情感深度 110%（情感穿透）

【不得偷渡】

低證據用高強度 = 編譯擋下
高證據用低強度 = 測試擋下
```

### 9. 三張卡差異化鐵律
```
【過去卡】
  語氣：沉、溯源、揭底
  重點：人格怎麼形成
  情感深度：+15%
  直接度：Normal

【現在卡】
  語氣：快、直接、刺痛

【未來卡】
  語氣：警告、預判

  直接度：+10%

三卡話術禁止相似度 > 0.72（既有去重檢查）。
```

---

### 10. 客戶個人化鐵律
```
【名字、性別、人格、時間層 = 完整個人化】

公式：
Name + DeclaredSex + ExpressionProfile + CardType + EvidenceLevel
  = PersonalizedAsuraSpeech

【不得偷工減料】

✅ 正確：「威諺，你外面撐得很硬。但真正重要的事，你其實比別人想得更深。」
❌ 錯誤1：「你屬於外剛內柔型。」（念分類，禁止）
❌ 錯誤2：「兄弟，你……」（只換稱呼不做交叉，禁止）
❌ 錯誤3：「因為你是男性，所以……」（性別刻板，禁止）

違反即測試擋下。
```
