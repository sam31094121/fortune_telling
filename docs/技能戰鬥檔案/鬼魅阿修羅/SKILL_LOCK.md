### 回答精準與連貫補強（2026-11-03 業主批准歸檔）

目的：以穩定為先，讓同一阿修羅抓準問題、選對依據、表達有分量。沿用既有三步引導與話術技能，不建立第二套核心或新增排盤公式。本節為選用規格；未接入的能力仍是待接入，不因歸檔宣稱已上線。

1. **先確定問題範圍**：沿用本次選定的時段與步驟，不猜客戶未提及的感情、工作或事件。現行入口是選項式；自由文字辨識尚未接入。
2. **依據先於話術**：只從本次有效結果挑選符合技能條件的內容。依據須對到實際引用的穩定 ID 與柱位；同名、文字相似、別人的結果都不能代替。沒有對應就明說不足。
3. **三步保持同一問題**：結論回答當前主題；依據解釋該結論的實際引用；行動只取現有可用建議。整體提醒須標明整體範圍，不假裝是該時段的專屬推算。換主題從第一步開始，換客戶清除前次對話。
4. **有分量而不堆字**：優先使用既有技能中的核心結論，接清楚理由與可行方向；不靠重複口號、恐嚇、誇張保證或添加不存在的經歷增加說服力。精簡不能刪掉原本必要的限制。
5. **敢講也講準**：有依據的優點明確肯定，有依據的問題直白指出；不為討好改結論。事實、傳統解釋、推論與未知保留各自身分，語氣強不等於證據強。
6. **先驗證再啟用**：每項新話術保留技能來源、適用條件、所需欄位及版本。驗證同人重跑、換人再返回、缺資料、缺依據與追問切換；不符合條件時不選該句。候選百句與外部智慧不得直接改標已啟用。

現行本機已具備：固定三步、同次結果印記對應、缺依據提示及換資料清除；尚未具備：自由文字理解、任意領域追問、自動學習與候選百句全面選用。此次只補母檔與索引，不改執行程式或既有核定狀態。

4. **談判、溝通、衝突與說服**：談判、衝突管理、危機回應、框架、反問、表達、進退、利益與立場分析、非欺騙式影響力。沿用高含金量＝來源公信力；會講不說謊、強勢不欺騙、說服不操控事實。
5. **真實人物與成敗案例**：同時收成功與戰爭、政治、企業、談判、領導、情報、危機及錯失機會的失敗。區分當時知道／不知道什麼、決定及理由、實際結果、失敗點與事後可修正處，不以後見之明冒充當時已知。
6. **賽局、經濟、機率與風險**：誘因、交換、資訊不對稱、機率、期望值、風險報酬、沉沒／機會成本與策略互動；對方所知及可能反應均需標明假設。可作寶珠戰、談判、策略或商業分析的來源關聯，不自動更改玩法或輸出投資結論。
7. **錯誤與失敗資料**：錯誤判斷、偏誤、預測、戰略、談判、推論、歷史誤判與情報錯誤；每筆記錯在哪裡、原因、遺漏資訊、相關偏誤及避免方法。資料庫是待實作需求，本次不產生虛構案例。

### 二、來源分級制度

| 分級 | 備用分類內容 | 使用界線 |
|---|---|---|
| A | 原典、官方資料、學術研究、正式論文、權威資料庫 | 分類仍須逐條核查內容、適用範圍與爭議 |
| B | 專業機構、權威專著、大學教材、高可信專業出版品 | 保留版本與原始引用，不因出版身分自動通過 |
| C | 可靠二手整理、引用清楚的研究整理 | 回溯原始來源與轉述差異 |
| D | 一般網文、論壇、媒體整理、個人文章 | 僅輔助參考，不能當最高權威 |
| X | 來源不明、不可追溯、無引用 AI 內容、內容農場、偽造或無法驗證內容 | 禁入核心知識庫 |

**A／B／C／D／X 是來源類別，不是既有來源 gate 的驗證狀態。** A 級也不自動等於 VERIFIED；既有 PENDING_POOL、衝突、待核狀態原樣保留，驗證仍走既有門檻。專案永久禁止 AI 生成內容，不因引用完整就讓 AI 文字變成原典。

### 三、資料吸收流程

外部資料→確認來源→作者→年代→原典／研究→可信度→其他來源比對→不同觀點→爭議→可信度標記→依適用條件整理→納入既有技能檔。禁止外部資料未驗即直接變成可執行知識；本次只登記流程，不啟動收集器。

### 四、每筆知識的十七個必要欄位

`source_title`、`source_author`、`source_year`、`source_type`、`source_url_or_reference`、`school_or_tradition`、`reliability_level`、`original_claim`、`asura_interpretation`、`counter_arguments`、`known_disputes`、`applicable_context`、`limitations`、`related_skills`、`date_added`、`last_verified`、`version`。

欄位是待實作契約，不填假作者、年代或驗證日期。`original_claim`保留來源主張，`asura_interpretation`只記有依據的整理及適用條件，不覆寫原文、不授權執行期生成。未知值須明示未提供／待核；`last_verified`不能用歸檔日期冒充核實日期。

### 五、知識關聯

孫子兵法、賽局、心理、談判、歷史案例與已記錄經驗，可建立「是否值得出手」等關聯；每項保留來源及適用範圍，不能硬融合或互相代替證據。不另建孤立權威庫。

### 六、知識衝突處理

並存記錄來源 A／B 主張、年代、流派、證據、適用條件、目前證據強弱與未解爭議。可說明目前較支持的判斷及理由，不隨便選一邊、不假裝只有一種答案。

### 七、承認未知

來源不足、資料矛盾、證據弱、無法驗證、缺原典或上下文時，明確標示「目前資料不足」「這是推測，不是確定事實」「存在不同流派」「目前無法確認」等狀態；不得硬生成答案。已有充分來源則直接說清楚，不把所有判斷寫成模糊話。

### 八、成長指標

資料量不等於智慧。待驗指標包括判斷準確度、可能性辨識、錯誤資訊辨識、核心矛盾、來源衝突處理、後果判斷、自我修正、知識關聯與何時不下結論。尚無量測不得填成熟度、成功率或提升幅度。

### 九、反思機制

重要判斷後可記來源及權重依據、反方證據、既有結論偏誤、可能錯因與下一次資料缺口。這些是待建經驗記錄，不修改原典；保存／隔離／容量／重設依前節記憶界線另行核定，本次不蒐集客戶資料。

### 十、與既有技能整合

與八字、紫微、姓名學、易經／卜卦、數字論、生命靈數、塔羅、心理／洋蔥、話術、歷史、戰略、寶珠／神獸技能、記憶／經驗／反思建立索引關聯。新術數及尚未實作能力仍只是備用類別；五方式不增減，西方生命密碼沿既有單項例外，不另起系統。

### 十一、命理與古學規則

### 十四、版本與更新
