### 已確認的產品規格

- 僅在新版 `/ghost-asura` 原內容最末方追加年度區，上方原有十年解讀與其他卡片不變。
- 五顆不同色的五角星以細線連接；當年前兩年、當年、後兩年共五年，當年居中預選，點選其他年不重新置中。年份與年齡由後端依既有契約提供；顏色只作視覺識別，不附加命理意義。
- 點選後在同一區顯示同一人、所選單年的解讀。最終依據須包含既有八字及紫微的年度適用結果，保留各自年界與來源，不以本命宮位冒充年度宮位。本命及大運只作適用背景，不以十年結論充當一年結論。
- 沿用阿修羅既有核定口吻，採洋蔥式：先呈現當年重點，再讓客戶逐層展開適用解讀與已有建議。各層不得重複拼貼；不能只將「十年」替換成「一年」。有幾層真實內容才呈現幾層，不為湊層數補句。
- 年度區視覺依[修圖技能](../../../.codex/skills/home-beast-entry-blending/SKILL.md#asura-retouch-integration)純 CSS／向量流程，對照同頁正式阿修羅實際樣式，使背景、邊線、文字、選中態及展開層一致；保留五色星與清楚切面，不改上方卡。以相同視口、年份與展開狀態比較修改前後，核對手機及桌面；4K 預覽須原生向量渲染至少 3840×2160，不放大小截圖冒充，不因此放大網站元件。
- 口吻強烈直接、重點先講，以有力短句逐層給出一個具體有用的新重點，少鋪陳、重複與空泛。只能合法選用、去重及呈現既有核定句，不為追求口氣改寫來源或新增命理斷語；沒有適用句就保留未取得。不用煽情、誇張或「保證發生」代替依據，八字與紫微核對不代表現實事件必然發生。此為年度區驗收要求，不改全卡既有話術，也不使尚缺映射的內容自動可用。
- 客戶畫面（含展開層）不呈現干支、十神、原始神煞、紫微宮星、計算來源或技術依據。前端只呈現後端提供的阿修羅口語、年份年齡及必要狀態；原始運算、穩定 ID、來源與適用範圍留在後端追溯。
- 追加用語收斂：新增區標題沿用現有「阿修羅秘卷」，第一層「命魂戰局」、第二層「阿修羅秘卷」；不再向客戶顯示「流年」、生肖或原始命理分類，連無障礙標籤一併核對。數字年份、年齡、通用操作與真實未取得提示保留；本節內部工程名稱不等於客戶可見用語。
- 不以 LLM 生成、隨機挑句、前端計算或別人的參考照片補內容。缺適用依據時顯示簡短中文「年度解讀暫時無法取得」；部分內容不標成完整雙系統整合。

### 實作現況與來源接點（本輪快照）

年度漏接修正（2026-11-26，取代前文僅 VERIFIED 的年度選句敘述）：45 個人年的 149 次 flow 觸發中，byId 缺條目為 0；27 次 VERIFIED 中有 20 次本命未命中、年度才命中，並未因缺本命項被擋。實際過窄條件是年度層 `crossCheckedRuleIds` 排除了 122 次非 VERIFIED 觸發。現對齊既有 `buildDualChartShenSha` 的正式輸出契約：來源 ready、outputStatus=READY，且 VERIFIED 或既有 referenceMethod 才能選；指定版本來源保留 PENDING_POOL／referenceMethod 身分，不能稱原典交叉驗證完成。resolver 只接年度 ID 與空本命柱位陣列，不借本命柱位作年度證據。正例為本命未命中的 2019 wenchang；三種負例（ready=false、BLOCKED_CORE、非 reference 的 PENDING_POOL）均不選。三案例 45 個人年改善為 44 個部分口語／1 個未取得；完整雙系統綜合結論仍為 0，不因來源放行修正而冒稱全面完成。

逐句來源精確化（2026-11-26）：annualLineAudit 現記錄實際 TIME_VOICE 時間框、beat／pair 鍵及句索引，或 resolveAsuraInterpretation 的 meaningStrong／advice 欄位；找不到原句來源即不以模糊來源標籤放行。這能驗證文字來源，不代表原句已通過全部年度語義審查。單年語氣攔截後重驗 45 個人年，仍為 44 個部分／1 個未取得，雙系統完整解讀 0；紫微限定提醒只在第二案例 2020、2030 命中。
