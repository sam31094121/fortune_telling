# 紅鸞與靈魂配對素材適用範圍

核對日期：2026-10-28。依業主要求，收錄既有靈魂配對材料供阿修羅查核，不把雙人分數轉為十四主星推薦。

## 本次功能

紅鸞只需客戶自己的出生資料。後端取得本次命宮主星，依「紅鸞-主星互補參考.json」完整條件找出對象主星參考及來源短句，前端沿時間、對象、互補方向、下一步的順序顯示。數量依條目，不固定三顆；不新增對方資料必填欄位。

| 材料 | 實際作用 | 紅鸞使用方式 |

## 實際接線

紅鸞的主星參考由 lib/red-luan-complement-reference.ts 讀取技能資料，lib/red-luan-heartbeat-engine.ts 傳入本次真實命盤。靈魂配對 API 已引用同一個 buildZiweiLovePersonSignal；不可反過來呼叫雙人 API 填紅鸞缺口，造成循環依賴或虛構對方資料。

十四單主星與二十四雙主星已有條目，但必須符合各自宮位與來源條件。命宮空宮且夫妻宮雙星仍缺同一來源的完整主輔判定；現有作者同時提及宮位、季節及日夜，未交代條件衝突時的優先次序，不自行加權或任選一星。

本文件為素材使用邊界，不是新增配對算法、核定來源或完成發布的證明。正式顯示仍只使用已登記的後端條目；缺內容維持明確狀態。
