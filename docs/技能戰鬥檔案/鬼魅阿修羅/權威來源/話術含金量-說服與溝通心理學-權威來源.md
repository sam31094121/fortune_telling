## 一、含金量怎麼定義（篩選標準）

1. 有沒有後設分析（多研究合併）。
2. 效果量多大（d、g、r，不能只說「顯著」）。
3. 有沒有校正發表偏誤。
4. 有沒有被大型預先註冊重現推翻。
5. 對誰有效（多為西方學生樣本，東亞未驗證）。

## 四、對阿修羅話術的意義（概念層）

- **證據上限是「小到中、有條件、會衰退」**：動機式晤談 d 從 0.77 降到 0.30 再到 0.11；敘事約 r=.17～.19；框架 d≈0.26～0.44；順從連續請求 r≈.15～.17；社會規範 d≈0.18～0.52（要看對照條件）。
- **有硬證據的方向**：讓對方自己說理由、給可代入的故事、換框架、給具體社會規範、稀少線索（依類型）。
- **不得宣稱的**：「大數據證明必有效」、成功率 X%、推力一定有效、意志力會耗竭、權威必定讓人服從。
- 稀少性、社會規範、權威的證據**不是同一種等級**：稀少性有大規模後設分析（416 個效果量）；社會規範證據偏永續行為情境；權威則只有說話者可信度的二手數字且彼此衝突。
- 五層結構（破／鎖／斷／立／行）只決定話術放哪一層，不改變上面的證據上限。
