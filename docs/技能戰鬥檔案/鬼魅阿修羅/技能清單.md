- 僅此卡的舊「易經老師／鬼魅老師」解說入口改為單一鬼魅阿修羅；其他卡片與各套公式不變。
- 順序：本次出生資料 → 既有紅鸞／紫微與易經運算和核對 → 後端整理時間、傳統對應對象、同一顆卦與行動提醒 → 前端照印。
- 開場逐字引用《阿修羅脾氣系統》現在卡模式「別再繞了。」；收尾逐字引用未來卡梗例「我先把話放這裡。你自己決定要不要踩。」。兩句只作口氣，不宣稱客戶有特定人格、過錯或經歷。
- 個人化內容只取本次既有 `nextEncounter/peakMonths`、`affinity` 與同一卦的 `essence/advice`。不新增起卦、不改月份、對象取法、來源狀態，不把欄位存在當成原典核定。
- 主解說不堆來源說明；來源保留在「完整推算過程與證據」的收合區。缺結果保持明確狀態，未知時辰仍不建立生辰卦。
- 實作位置：`lib/red-luan-iching-reading.ts`；前端沿用 `teachers` 陣列契約，內容只有 `asura` 一項。測試：`npm run test:red-luan-heartbeat`。
- 全部核定仍以既有健康檢查為準，本限定話術調整不解除來源待核，也不代表全站驗收完成。驗收後恢復凍結。
- 本輪驗收：紅鸞規則／後續動作／前端誠實性測試通過，四項請求生命週期測試通過，修改檔 ESLint 與全專案 TypeScript 檢查通過。瀏覽器以 1974-06-28、男性、酉時合成測例重算，月份仍為 2027 年 1 月、卦仍為地澤臨；單一阿修羅入口可展開，來源獨立收合。390px 模擬寬度未見水平溢出，非真機驗收。既有來源健康檢查仍失敗，因此本輪未自動提交推送。
