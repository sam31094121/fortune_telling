## 一、唯一順序（資料鏈＋組句順序）

### 1.1 資料鏈（不得顛倒；程式常數 `ASURA_CHAIN`）

1. 填寫資料
2. 八字命盤（四柱唯一來源 `lib/bazi/engine.ts`）
3. 紫微斗數＋四柱逐字核對：對不上就停在核對關，不顯示、不往下走，也不自動改任一套
4. 易經姓名學
5. 易經卜卦
6. 公信力閘（來源等級、交叉比對、核對結果）：決定這句話能說多強
7. 阿修羅話術：從句庫挑一句
8. 前端只照印

- 三核心（八字、紫微斗數、易經）的先後只有一份：`lib/credibility-phrases.ts` 的 `CORE_ORDER`；本檔與程式不另訂第二套，測試確認相對順序一致。
- 與鎖定的「五種方式」一致：八字、紫微、姓名學、卜卦、鬼滅阿修羅。
- **實作現況**：只接第 2、3 步。姓名學、卜卦的結果尚未參與挑句；公信力閘已有函式（`credibilityTier`），尚未用來改變句子的語氣。

### 1.2 組句順序（程式常數 `WORDING_COMPOSITION`，來自實戰話術範例〈〇〉）

1. **開場**：直指「你」，帶反差或懸念（客戶前三秒決定讀不讀）
2. **事實**：說他資料裡真的有的，附出處與公信力
3. **看見**：這件事對他意味著什麼
4. **動作**：一個他自己能做的小動作

資料鏈決定「說什麼事實」，組句順序決定「怎麼說」，兩條順序各管各的，不互相取代。

## 二、含金量＝公信力等級（力道由它決定）

公信力不是我們宣稱的，是**閘門算出來的**。來源等級與狀態規則見 `../易經/來源治理.md`、`lib/iching-source-gate.ts`；客戶看得到的說法只能照 `STATUS_WORDING`。

| 公信力條件 | 閘門／核對怎麼算 | 對話術的意義 |
|---|---|---|
| 來源等級 | A 原典／研究圖書館書目、B 大學出版與學術、C 公開數位文本、D 以下只進候選區 | 越高，越能引用出處 |
| 交叉比對 | VERIFIED／CONFLICT／PENDING_POOL（閘門重算，不得手填） | 只有 VERIFIED 能說「已通過交叉比對」 |
| 四柱核對 | 八字×紫微逐字一致 | 沒過就停在核對關 |
| 時辰 | 客戶有沒有填 | 沒填就明講暫以夜半起算 |
| 客戶確認 | 客戶點「確認無誤」（畫面尚無此按鈕，未實作） | 輸入沒填錯的必要條件，不是充分條件 |

### 2.1 力道等級（程式 `credibilityTier`，草案，待業主審）

| 等級 | 條件 | 語氣 |
|---|---|---|
| 強 | 四柱核對通過＋來源 VERIFIED＋客戶確認無誤，三項缺一不可 | 對事實最篤定：已、必、早 |
| 中 | 資料算得出來，但來源待核或客戶尚未確認 | 陳述事實，不加「必」 |
| 弱 | 沒填時辰，或來源互相衝突 | 只說已知範圍，明講暫排 |
| 擋 | 四柱核對沒過、紫微未定盤、出錯 | 不說，顯示「資料核對未通過，暫不顯示」（客戶看得到的字不用「四柱」等術語） |

- **各項來源的狀態一律以閘門重算為準，本檔與句庫不寫死「幾項 VERIFIED」**（2026-10-24 重算：八字 17 項中 11 項 VERIFIED，含八字四柱排盤正確性與天乙、文昌、咸池、驛馬、華蓋等指定取法；紫微斗數 5 項中 0 項；易經 13 項中 1 項）。此數字會隨來源登記變動，引用時須重算。
- 依此：吉類神煞（天乙、文昌）的來源已是 VERIFIED，不因「神煞」二字就降級；**依紫微斗數內容的句子，因紫微目前 0 項 VERIFIED，力道最高到中**。是否 VERIFIED 看該句對應的那一項，不看大類。
- 客戶看得到的提示（核對沒過、查無資料）同樣不得出現術語，一律用白話，且納入術語守門。
- **一句話界線：事實說死，結果不說死。**頂到天花板＝對事實最篤定，不是可以寫「必定」「準確度」。

## 三、攻心：怎麼讓同一個事實更有力

沿用實戰話術範例〈〇〉，並加上公信力：

1. **直指你**：第一句讓人覺得在說他，不先講名詞。
2. **帶反差**：「不是…是…」，讓人想知道下一句。
3. **亮依據**：事實後面跟一個能指出來的出處。**已實作（業主批准 2026-10-24）**：卡片在句子下方以小字照印後端組好的「依據」一句，只用已核准的公信力句子（`APPROVED_PHRASES.crossCheck`、`traditionBoundary`）與閘門狀態說法（`STATUS_WORDING`），不比閘門狀態說得更滿；沒填時辰就明講暫以夜半起算、核對尚未進行；核對沒過則不顯示。
4. **短**：每句不超過 16 字，一口氣讀完。
5. **結尾一個動作**：他自己能做的事。

## 四、氣：硬骨不等於兇

- 硬在**立場**，不在對客人的態度：輕蔑只對阻礙，不對人。
- 短、只陳述、留白。力道藏在名詞與動詞，不堆形容詞。
- 如實說明資料狀況也是硬骨：沒填時辰就說「暫以夜半起算」，與卡片既有提示一致；**句子不得自稱「不補編」**，因為顯示管線確實會以子時暫排，說反了就是自己打臉。
- 句子不隨日期變，**不得寫「今日」**；要有日期感，須由後端依日期輪替。
- 可以霸，不可以嚇。預見用完成式，是姿態，不是對他人生的預言。

## 五、料：資料決定哪一句，後端挑，前端照印

- 依客戶實際填寫的資料觸發（日元、月令、時辰有無、五行、吉類神煞…）。每句的事實依據記在句庫的 `factBasis`。
- **後端沒有該欄位，該句不顯示**，改顯示明確中文狀態（「暫時無法取得」）。不得用別句頂替。
- 一人一句：同一位客戶一屏只出現一句主話術。
- 每句須標出處（五種方式之一的檔名＋行號）。

## 六、界：能說到哪裡

### 6.1 公信力上限（必讀）

- 阿修羅能說多強，由第二節的等級決定；**沒有任何一級可以保證結果**。
- 沒有國家級認證機構，禁止宣稱國家認證。
- 古籍與排盤正確性有公信力，**不等於科學已證實**；三核心是傳統與文化詮釋，不是科學證實的預測（`APPROVED_PHRASES`）。

### 6.2 不得宣稱（對內文件、對外話術、畫面、行銷一律適用）

- 「大數據證明」「全世界最有效」「科學已證實」「準確度 X%」「成功率 X%」
- 「國家認證」「權威認證」（沒有國家級認證機構）
- 「保證」「必定」「註定」「一定會」
- 把 PENDING_POOL 的說成「已驗證」；把二手轉述的數字當已核對
- 把已被推翻的當證據：意志力耗竭、推力整體有效、服從權威必然成立

### 6.3 可以說的

- 對已核對的事實直陳，並依閘門狀態用 `STATUS_WORDING` 的說法描述來源
- 本錢、方向、一個小動作、一個看見
- 提醒類只講提醒與轉化（殼與禮物），不恐嚇、不診斷、不預言事件

### 6.4 要老實標出的限制

- **個人化程度有限**：目前可接 8 個構面 × 10 個日元，同一類客戶會拿到同一句；這是「分類後的一句」，不是為他量身寫的一句。
- **巴納姆效應**：泛用的話人人覺得像在說自己；讀起來準不等於有公信力，更不能當準確度的證據。
- **門檻是自訂的**：偏旺門檻 0.45、挑句優先序是工程啟發式，不是古籍規則。
- **句庫本身不是 VERIFIED**：已登記但無第三方交叉來源，閘門算出 PENDING_POOL，不得寫「已通過交叉比對」；「依據」一句講的是句子所用**事實**的來源狀態，不是句子本身。
- **等級函式尚未改變語氣**：句庫目前一個構面一句、沒有強中弱三種語氣版本。

## 七、阿修羅的個性與授權（業主定案 2026-10-24）

**個性**：敢說、敢做、敢戰、敢講；強項是解盤、預見好壞、幫人解圍；也看跟阿修羅有沒有緣。

**授權規則**：只要數據正確（公信力與公權力的檔案、技能檔為依據、四柱逐字核對通過、來源已核定），阿修羅就敢說、敢衝、敢講，力道依〈二〉分級，數據越確定，語氣越篤定。

| 強項 | 怎麼說到最強，又不越界 |
|---|---|
| 解盤 | 對已核對的事實直陳，用「已」「必」；八字、紫微、姓名學、卜卦的結果各自標出處 |
| 預見好壞 | 說**走向與時機**：流年、大運對日元是助力還是消耗，哪一段出手、哪一段收。依確定性運算（大運、流年），不編事件、不寫具體日期與人事 |
| 解圍 | 每一個提醒都配一個可做的動作；壞的一面只講提醒與轉化，不說「會出事」 |
| 有沒有緣 | 以靈魂配對的運算結果為準，不憑空宣稱「天定」 |

**一句話界線**：數據正確，事實就說死；結果沒有任何數據能保證，結果就不說死。敢說的範圍＝數據撐得住的範圍。

## 八、轉化承諾（業主定案 2026-10-24：改運須以對社會有貢獻的條件交換）

- **名稱**：一律稱「轉化承諾」，不稱「改運」或「交換」。客戶自己從清單選一件對社會有貢獻的事（捐血、淨灘、陪伴長輩、志工時數、固定捐給第三方公益等），阿修羅依其資料點出適合從哪一類出手，並給一個具體動作。
- **承諾行動，不承諾結果**：可說「這件事做了，局會往這個方向調」；不得說「做了就改運、轉好、避禍」。
- **錢不進本站**：條件不含任何付費給本站、買符、買法事；若涉及捐款，須直接捐給第三方且可查證，本站不經手、不抽成。上線前須請法律專業人士確認，**本檔未核對各地法規**。
- **不借運、不替人消災、不賣符咒**（沿用鬼魅老師人設）。
- **沒做也不嚇人**：不得說「你會倒楣」；只說「這件事還沒做，隨時可以做」。
- **完成與否**：本站無法驗證客戶是否真的完成，「完成」只能是客戶自行勾選，不得當成證明，也不得當成力道升級的依據。
- **尚未實作**：清單、勾選、儲存、畫面都還沒做；個人資料要不要留存、留多久，待業主決定。
