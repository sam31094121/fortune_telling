# 首頁箴言修圖規則（阿修羅修圖檔案）

業主定案 2026-11-10。對象：首頁最上方箴言木板卡（`app/page.tsx` 的 `home-top-motto-link`）。
CSS 單一來源：`app/globals.css` 的 `HOME_TOP_ASURA_RETOUCH_V1` ～ `END_HOME_TOP_ASURA_RETOUCH_V1` 區塊。

## 一、不可動
1. 文字一字不改：「順天而行，」「感恩的心」「逆天而行」「＝」「米田共」。
2. 字型家族不改（Ma Shan Zheng／Noto Serif TC 等維持）。
3. 版面比例、木板、太極主視覺不動。
4. 這張卡不產生新內容；文字是固定箴言，不屬 AI 生成。

## 二、可動（視覺感官）
- 字形質感：金箔邊、浮雕厚度、墨色濃淡與暗紅描邊——全部**靜態**烘進字形（text-shadow、text-stroke、漸層）。
- 動畫：只准 `transform`、`opacity`。

## 三、手機不卡頓條件
1. 動畫（@keyframes `home-asura-*`）內禁止 `filter`、`background-position`、`box-shadow`、`color`、`mix-blend-mode`。
2. 這張卡同時運行的動畫上限 6 個，每個元素只掛 1 個動畫。
3. 動畫圖層一律預先畫好（偽元素＋`will-change: transform, opacity`），不在動畫中重繪文字。
4. 區塊內不得使用 `mix-blend-mode: screen／multiply`。
5. `prefers-reduced-motion: reduce` 全部關閉動畫。
6. 動畫之間用 `animation-delay` 錯開，一次只有一個焦點在動。

## 四、驗收
- 守門：`npm run test:home-motto-retouch`（文字未改、字型家族未改、動畫屬性白名單、動畫數上限）。
- 實跑：手機寬度 390 開首頁，看畫面與主控台無錯誤。
- 仍缺：Samsung 等真機的掉幀實測（本檔案無法以桌面環境代替）。
