## 〇、說服力與攻心力規範（2026-10-15 列入技能檔案）

> 本節是所有鬼魅阿修羅話術的**共同寫作規範**，手寫話術與自動生成話術都要遵守。
> 沒有另開新檔：規範放這裡，程式實作在下面〈落地位置〉，守門測試擋退步。

### 一、開場攻心力（客戶讀到的前三秒）

開場句是客戶打開頁面第一眼讀到的那一行（`shortDeclaration`／印記標題宣告），決定他讀不讀下去。五條：

1. **直指「你」**：第一句要讓人覺得在說自己，不先講名詞、背景或術語。
2. **帶一個反差或懸念**：「不是…是…」「別人…你卻…」「有一處你得先看清…」，讓人想知道下一句。
3. **承諾一個價值**：讀完能帶走什麼（一個看見，或一個本錢）。
4. **短**：開場句約 20 字內，一口氣讀完；核心句約 40 字內。
5. **不恐嚇、不下斷言**：不用「你一定會…」開場；懸念來自反差，不來自嚇人。

| 弱開場（只有名詞） | 強開場（直指你＋懸念＋價值） |
|---|---|
| 隔著一道牆。 | 有一處你得先看清：「隔著一道牆」。 |
| 最大的貴人。 | 「最大的貴人」在你這邊：這是本錢，別讓它閒著。 |
| 有人替你開門。（已合格） | 直指「你」、一句話帶出價值，沿用不改。 |
| 永遠在移動。但別理解成逃離，那是進攻。（已合格） | 反差「不是逃離，是進攻」，沿用不改。 |

### 二、價值感（讀完帶走什麼）

每一條話術都要讓人帶走**兩樣東西**：一個「看見」（原來我是這樣）＋一個「動作」（所以我可以這樣做）。
只有氣勢沒有動作，是喊口號；只有動作沒有看見，是雞湯。

### 三、五條說服力規則

1. **講具體場景**：搬家、轉職、開會、對帳，讓人對號入座；場景只能出自已驗證的命盤證據，不捏造經歷。
2. **兩面並陳**：好處與代價一起說（配得好…配不好…），只報喜或只報憂都不可信。
3. **不超額宣稱**：神煞與星曜是形容詞，走勢看整體條件；不說單一印記決定一切。
4. **結尾給一個可做的小動作**：句型要有變化（「下次…」「今天…」「開會前…」「打開抽屜…」），不全部用同一個起頭。
5. **有依據才引用**：能追到來源才說來源；查無依據只說「通行的讀法」，不稱國家認證、不稱科學證實。

### 四、紅線

不恐嚇、不下斷言（禁「必定、一定會、註定、大凶、血光」等）、不診斷、不預言事件、不偷看客戶資料、
不宣稱準確度；凶煞只講提醒與轉化。

### 五、落地位置（唯一來源，不得另開第二份）

- 客戶頁手寫話術**正本**：`features/ghost-asura/wordings.ts`（含 `customerWordings.ts`）。
- 同名條目必須逐字同步到 `lib/ghost-asura-wordings-core.ts`（雙命盤頁卡片）與 `lib/ghost-asura-complete-dictionary.ts`（技能層）。
- 自動生成層：`features/ghost-asura/skill/entries.ts`（開場句 `DECLARATION_BY_POLARITY`、戰局句 `BATTLE_BY_POLARITY`），解析器 `skill/resolver.ts` 依編號決定性挑句型。
- 守門：`npm run test:ghost-asura-customer-output`（免登入、掃 4 張鎖定命盤的每個顯示字、三份庫一致、翻譯層引用行號有效），已進推送閘。
- 紫微老師的同一套規範：`docs/技能戰鬥檔案/紫微斗數/話術強化.md`。

### 六、功能話術提升通用標準：不給面子的阿修羅口氣（2026-10-28 列入技能檔案）

> 凡後續任何卡片或模組申請「以阿修羅技能檔案提升功能的話術」，一律套用本條**「不給面子 ＋ 敢說、敢講、敢做、敢衝、敢戰」**口氣標準與 `阿修羅脾氣系統.md`〈實歲戰局直斷規範 v2.2〉：

1. **不給面子（當面撕掉遮羞布）**：
   - 零客套、零奉承、不留台階。開頭直接拆穿客戶用來自欺的正面偽裝（例如把「溫和合群」拆穿為「怕被孤立的軟柿子」、把「深思熟慮」拆穿為「怕輸怕丟臉的縮頭軍師」、把「照顧人」拆穿為「用苦勞刷存在感的控制狂」）。
   - 嚴禁對年輕人用家長／輔導老師口吻哄騙（如「天塌不下來」），嚴禁對年長者拍馬屁（如「格局無人能及」）。
2. **敢說、敢講（醜話攤上檯面）**：
   - 禁止下達「閉嘴忍耐、退居幕後、少管閒事」等消極退縮指令。
   - 命令客戶看穿破綻就**敢當面講清醜話、敢把底牌拍上談判桌、敢當眾掀開假面具**。
3. **敢做、敢衝、敢戰（正面攻堅破局）**：
   - 禁止下達「先把爪子收起來、退後一步、封刀斂氣」等踩煞車指令。
   - 命令客戶**炸毀退路、跳進戰壕、鎖定最硬的主戰場正面死磕、帶隊搶下主導權**。
4. **實歲四階段定錨與去模板化**：
   - 涉及時間軸（以前／現在／未來）時，必須由後端確定性計算實歲（`completedAge`，過完生日當天始加 1 歲；16／32／48 歲生日未到嚴禁提前換階），對應 `1–16 歲（早年扎根期）`、`17–32 歲（破陣立業期）`、`33–48 歲（中場扛局期）`、`49 歲以上（統帥定局期）` 講符合該年紀戰局的狠話。
   - 廢除「問題是……方向是……」與「只有兩條路：第一條路／第二條路」的公版填空模板；每分句嚴格受 `lintAsuraVoice` 守門（$\le 16$ 字、零問號、零驚嘆號、跨卡零重複分句）。
