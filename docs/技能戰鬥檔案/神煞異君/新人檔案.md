# 《神煞異君》新人檔案

《神煞易經》的另一張臉。業主定案 2026-09-28：同一張盤，兩位老師——**易經老師是神，鬼魅老師是魔**。
正式檔：[神煞異君.json](神煞異君.json)；姊妹技能：[../神煞易經/](../神煞易經/新人檔案.md)。

## 一、兩張卡，一神一魔

| | 易經老師解盤（《神煞易經》） | 鬼魅老師解盤（《神煞異君》） |
|---|---|---|
| 口吻 | 溫和的智慧、導師 | 茅山道士、門外低語 |
| 開場 | 衍生鏈、本命卦、導師總覽 | 開壇：「茅山的規矩：先驗四柱，再開壇」 |
| 神煞 | 本意→意境→柱位→落地＋洋蔥三層 | 逐柱點氣：護身符／壓陣的活氣／門縫裡的風 |
| 組合 | 整盤合看 | 陣法（陣名帶柱位） |
| 收尾 | 出處與公信力 | 收壇：「門我替你開過了，燈要你自己點」 |
| 配色 | 金紫 | 暗紅黑、楷體 |

兩張都在四柱神煞表下方，**折疊點閱**；四柱神煞表本身永遠直接顯示。

## 二、同一條後端

客戶資料 → 八字 → 紫微（四柱逐字核對）→ 特星神煞 → 易經起卦，兩位老師共用，不另算。
鬼魅老師只換說法：`lib/shensha-ghost.ts` 讀易經老師的結果（神煞、分組、組合、卦），另組一套話，前端 `ShenShaGhostSection` 只照印。

## 鬼魅老師是誰

他學過茅山，也在泰國見過黑衣阿贊的陰法；看過借運、下降頭的人付出代價，也看過滿街的詐騙。所以他的規矩是**只看、只解、不下**。完整人設：[鬼魅老師人設.md](鬼魅老師人設.md)。

## 三、界線（恐怖是外殼、知己是內核）

- 參考資料〈茅山傳承〉本身就批評有人借茅山名義恐嚇百姓——**茅山正統不以恐嚇立教**，本派鬼魅老師照此守線。
- 不說會出事、不說外靈附身、不賣符咒、不作驅邪法事或預言。
- 「符」只是比喻：你自己一路積下來的護身符。
- 每一句最後都回到你自己能做的事。
