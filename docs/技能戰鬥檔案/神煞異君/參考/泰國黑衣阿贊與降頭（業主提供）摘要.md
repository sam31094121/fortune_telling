## 一、黑衣與白衣阿贊（概念）

- 「阿贊」（Ajarn）意指導師、師父；民間法師不屬正統上座部佛教僧侶。
- **白衣阿贊**：守佛教五戒，協助祈福、招財、人緣刺青、驅邪，民間視為正道。
- **黑衣阿贊**：不拘戒律，鑽研控靈、詛咒、降頭、情降等偏門或攻擊性法術；傳說修行地點多在墓地、火葬場、荒野。

## 二、常見類型（概念層次）

- **降頭**：民間傳說以對方的生辰、頭髮、衣物、照片等為媒介施術。
- **情降**：傳說用來強行扭轉他人心意。
- **陰牌、鬼仔（古曼童的邪化傳說）**：被包裝成快速求財、求名或報復的法物販售。

## 三、歷史根基（整理說法）

泰國法術（Saiyasart）被描述為多種文化的混合：
1. 泰北與東北部（依善）萬物有靈的薩滿信仰。
2. 古代高棉（吳哥王朝）宮廷密術，隨泰柬長期交流流入邊境。
3. 一說源自中國西南（雲南、貴州、四川）苗疆蠱術南傳。
4. 印度婆羅門教咒語（Mantra）影響。

## 四、社會與法律的態度、以及「話術」的真相

- 泰國政府與正統佛教（僧伽會）否定黑巫術；主流社會視接觸黑衣阿贊、供奉陰牌為玩火自焚。
- 涉及盜墓、屍體、下毒、詐騙者，受法律制裁。
- 民間傳說強調「反噬」與業力：害人或借運必付代價。
- 「降頭」一詞的流行，被指與 1970 年代港片（例：邵氏《降頭》）的渲染有關；古代泰國人並不這樣稱呼。
- 多數泰國人是一般佛教徒；網路上宣稱「立刻斬桃花、降頭復合」者，多為針對外國遊客的商業詐騙。
- 網路文章亦提醒：沒有不勞而獲的法；改變仍需自己的付出、選擇與行動。
