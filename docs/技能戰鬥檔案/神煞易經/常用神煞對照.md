# 常用神煞對照（融入《神煞易經》，業主定案 2026-09-27）

參考原文：[參考/常用神煞總覽（業主提供原文）.md](參考/常用神煞總覽（業主提供原文）.md)（D 級候選資料，不是原典）。
本檔說明這份總覽怎麼「融入、貫通、使用」到本派，以及哪些不照搬。

## 一、融入了什麼（後端已在用）

1. **傳統三分類**：吉神貴人／凶煞惡星／動態中性。已算的神煞凡在總覽中出現，後端都附上「傳統分類」（`lib/shensha-teacher-readings.ts` 的 `SHENSHA_TRADITION`），和本派三類（福氣／動能／提醒）並列，讓客戶看得到兩種讀法。
2. **命理師的真心話 → 本派解盤原則**：神煞是命盤的「形容詞」；真正決定格局的是五行生剋與十神。這句原則由後端放進導師解盤總覽，提醒客戶不要只看神煞下結論。
3. **凶煞不等於不幸**：總覽也說「凶煞並不代表一定會發生不幸，格局好反而轉化為衝勁」，與本派「殼與禮物」一致；本派的提醒類一律講提醒與轉化。
4. **桃花歸動態中性**：總覽把咸池桃花列在動態與中性（配合得當主魅力，配合不當易生糾紛），本派桃花由「福氣」改為「動能」。外桃花維持業主定案的「牆外的好人緣」（福氣）。

## 隔角語源（2026-09-28，業主提供，D 級參考）

原文：[參考/隔角語源（業主提供原文）.md](參考/隔角語源（業主提供原文）.md)。

- **融入**：隔角導師話術加入語源——「隔」是日支與該柱之間隔了一位；古說寅申巳亥為天地四角，地支轉到此被阻隔。意境改寫為「羅盤上的四個轉角，路沒有斷，只是得轉個身」。
- **不照搬**：「骨肉分離、親友緣薄、官非牢獄」等斷語不寫；《鬼谷子》「枉多隔角」未附版本頁碼，不當原典引用。
- **不接入本卡**：風水「隔角煞（尖角煞）」屬居家風水，不是八字神煞。
- **不影響取法與登記**：本卡隔角仍為本派取法（日支順數兩位，查年月時）。八字來源登記 `C-DUAL-SHENSHA-GEJIAO` 是舊神峰通考取法的登記，閘門依其三份已登記來源算出 VERIFIED、登記表仍寫 PENDING_POOL；改登記狀態須業主親自確認修改（第 1053 行），本參考資料不能作為改狀態的依據。

|---|---|

| 「犯罪或遇官司往往能獲得寬大處理」（天赦） | 不寫涉法承諾。 |
