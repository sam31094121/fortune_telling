# 《神煞易經》新人檔案

本站自家一派「太極紫微易經派」。業主定案 2026-09-27：八字、紫微、神煞、易經有邏輯地融會貫通，叫做《神煞易經》，以後獨立門派。
正式檔：[神煞易經.json](神煞易經.json)。

## 一、一條線，順序不可顛倒

```
客戶填寫資料
 → ① 八字命盤（四柱唯一來源 lib/bazi/engine.ts）
 → ② 紫微斗數（四柱逐字核對；對不上就停，不自動改任一套）
 → ③ 特星神煞（太極紫微易經派取法；紙本命盤 17 項為標準答案）
 → ④ 易經（同一張已核對的盤帶憑證起卦）
 → ⑤ 導師話術　本意 → 意境 → 柱位 → 落地
 → ⑥ 洋蔥心理學　殼（別人看到的你）→ 心（其實的你）→ 禮物（這個神煞送你的）
 → ⑦ 字的意境　逐字取姓名學字庫原文
 → 前端只顯示（前端禁止生成）
```

讀法：**讀意、讀位、讀卦、讀心**。先讀神煞本意，再看它落在哪一柱（年＝根與門面、月＝環境與舞台、日＝自己與枕邊人、時＝出口與晚景），回到生辰卦的行動建議，最後剝洋蔥看到禮物。
整體再分「福氣／動能／提醒」三類；提醒不是壞消息，是先把燈點亮。

範例｜外桃花：牆外的好人緣——異性緣好、外面的貴人多。
殼：別人看你異性緣好、外面貴人多。心：其實你很會看場合調整自己。禮物：這份察言觀色是天賦，記得留一個不必表演的自己給最親的人。
心理學：自我監控（Snyder, 1974）。

## 三、公信力三分法（不得說得比閘門更滿）

1. **古籍權威**：有原典頁碼的神煞附頁碼；本派取法標＊「原典頁碼待補」。
2. **排盤正確性**：四柱核對、紙本 17/17、決定性（同盤同卦同話術），由測試守住。
3. **心理學**：名詞有原始文獻，但話術是本派自撰的自我反思，不是診斷，也不是科學證實命理。

狀態由 `lib/iching-source-gate.ts` 重算：目前 C-SHENSHA-ICHING、C-SHENSHA-ONION 皆為「仍在查證中，僅作自我反思參考」（外部授權待人工查核）。只有 VERIFIED 才能說「已通過交叉比對」。
