## 二、筆畫怎麼算（引擎實際公式，畫面會用這個名字實際的字帶入）

| 格 | 公式 |
|---|---|
| 天格 | 姓（第一字）筆畫 ＋ 1 |
| 人格 | 姓筆畫 ＋ 名首字筆畫 |
| 地格 | 名字筆畫加總；單名再 ＋ 1 |
| 外格 | 總格 − 人格 ＋ 1（最少取 2） |
| 總格 | 全名筆畫加總 |

範例：黃（12）美（9）燕（16）→ 天格 13、人格 21、地格 25、外格 17、總格 37。

## 三、各格代表什麼（流派說法，不是經典）

天格＝先天底色、人格＝核心個性（主運）、地格＝基礎與前期（前運）、外格＝外在人際（副運）、總格＝整體與後期（後運）。這些角色說法來自通俗整理，**尚未逐條對照原書**，畫面一律標「流派說法」。

## 五、誠實界線（鐵律）

- 五格與八十一數理屬姓名學流派約定，**不是易經經典，也不是科學已證實的預測**。
- 可追到的一手出處只有熊崎健翁著作的圖書館書目紀錄；**書內逐條原文尚未取得**，數理話術是白話改寫，不得寫成古籍原文。
- **筆畫差異必須照實講**：本站採 CNS11643 總筆畫；傳統流派多用《康熙字典》筆畫，部首變形的字（三點水、草字頭、示字旁等）有時差一到三畫，本站**沒有做康熙筆畫換算**，不得宣稱與康熙字典一致。
- 網路上「1918 年創立」「十八世紀末」等說法彼此矛盾且無圖書館佐證，不採用。
- 數字五行（1·2 木、3·4 火、5·6 土、7·8 金、9·0 水）與河圖「一六水、二七火、三八木、四九金、五十土」是兩套配法，不互為來源。
- 話術只講特質與提醒：不下吉凶定論，不用「必定、註定、大凶、血光、剋夫、剋妻、短命」等字眼（守門會擋）。
- 姓名五行與八字命盤的對照走既有的 `buildNameologyBaziCrossCheck`，不自動等於喜用神，也不宣稱改名吉凶；三合一整合層不受影響。
- 前端不得自己組句；瀏覽器保留的舊格式結果，元件要直接不顯示，不得讓整頁當掉。
