# 紫微斗數｜話術強化（說服力規範）

> **來源分級：D 級候選資料。** 素材是業主 2026-10-13 貼入的「八字神煞常用整理」，原文已存在
> `docs/技能戰鬥檔案/易經神煞/參考/常用神煞總覽（業主提供原文）.md`，**這裡不再重複存一份**，只引用。
> 它是八字神煞的整理，**不是紫微斗數古籍**：只借「說話方法」與「現代場景對應」，
> 不得拿來改星曜位置、亮度、四化，也不得寫成出自《紫微斗數全書》。

## 一、五條說服力規則（紫微話術一律適用）

1. **講具體場景**：不說「事業有變動」，說「搬家、轉職、出差的次數會比別人多」。讓人對號入座。
2. **兩面都說**：好的一面與代價並列（例：配得好越動越發達、配不好只剩奔波）。只報喜不報憂，可信度反而低。
3. **不超額宣稱**：星曜、雜曜是「形容詞」，決定走勢的是整張盤的星曜組合、亮度、四化與三方四正。話術要明講「我描述的是你手上的牌」。
4. **給一個可做的下一步**：每段收在一個可執行的動作，不收在宿命。

5. **有依據才引用（公信力第一）**：只要紫微斗數有權威依據，話術就主動用它背書。這裡的「公權力」指的是《紫微斗數全書》口訣＋獨立計算逐盤核對；**沒有國家級認證機構，禁止宣稱國家認證，也不得宣稱科學已證實**。依據只證明「位置排得對」，不證明「預測準」。引用的上限由後端依據表決定：`lib/ziwei/wording-authority.ts`（資料取自 `data/ziwei/quanshu-coverage.json`），三位老師的 prompt 都會帶上這張表，守門 `npm run test:ziwei-wording-authority`。

## 三、紅線

- 凶星只講提醒與轉化，禁用「一定會、註定、大凶、必然、血光」等字。
- 不得寫成科學已證實；古籍權威、排盤正確性、科學效度三件事分開講。
- 前端不組句：話術由後端產出（`lib/ziwei-teacher/`），前端只照印。
