四張卡（千歲壽、障月、障日、一剎那）標示「約幾歲到幾歲」與過去／現在／未來，並列出傳統對應與統計背景。
實作：`lib/ghost-asura-life-stages.ts`（後端運算、前端只照印）；守門：`npm run test:ghost-asura-life-stages`；登記：`C-ASURA-LIFE-STAGES`（狀態由閘門算，目前為**衝突**，原因見下，這是如實登記，不是缺陷）。

### 查證結果（誰有、誰沒有）

| 問題 | 結論 | 依據 |
|---|---|---|
| 古籍有沒有寫「某一柱管幾歲到幾歲」 | **沒有** | 《淵海子平》（維基文庫，頁面標示未完成）〈詳解定真論〉〈看命入式〉把年月日時分給祖上、父母、自身（日支妻妾）、子息；〈論月令〉只說年對應早年；三節皆無歲數 |
| 「1–16／17–32／33–48／49 歲以後」從哪來 | 後世通行簡化，出自現代命理網站，各家分界略有不同 | 二手來源；本站畫面明示「不是古籍原文」 |
| 有沒有大數據證明某柱會在某歲數應驗某事 | **沒有** | 沒有找到同儕審查研究或大規模統計；八字公信力登記同樣是「待驗證」 |
| 有沒有政府機關的真實統計可以當人生階段背景 | **有，但只能當背景** | 內政部統計處：108 年生育第 1 胎生母平均年齡 31 歲（內政統計通報 109 年第 20 週）；勞動部：114 年勞工生活及就業狀況調查，已規劃退休者平均規劃 60.9 歲（僅 14.6% 已規劃，有效樣本 4,029） |
| 有沒有學術上公認的人生階段理論 | **有，但年齡是「約」** | 艾瑞克森心理社會發展八階段（1950）、阿奈特成年初顯期（2000，約 18–29 歲）、列文森成人發展分期（1978，約 40–45 歲中年轉換期）；二手整理，頁碼待查證 |

### 對客戶可以說、不可以說

- **可以說**：「傳統上這一段對應祖上與早年」「政府統計顯示，108 年首胎生母平均年齡是 31 歲」「發展心理學稱這段是成年初顯期」。
- **不可以說**：「大數據證實」「科學已證實」「國家認證」「古籍記載 1 到 16 歲」「你這個歲數一定會…」。
- 統計數字一律同時標機關、年度與口徑；只引用本站實際讀過原頁的數字（初婚平均年齡雖在戶政司資料集內，但該 CSV 只有 22 縣市、沒有全國列，所以不引用）。
- 古籍沒有把「晚年」對應給時柱，話術不得硬寫；時柱只寫古籍有的「子息」。
