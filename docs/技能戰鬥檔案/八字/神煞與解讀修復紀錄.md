## 已確認的根因與影響

1. 雙命盤神煞四欄原本由 `C-RED-LUAN-SHENSHA` 一起控制；此主張涵蓋紅鸞月份及外型／職業詮釋，不是四柱神煞。四欄同顯示「未校驗」不表示四柱計算全部失敗。
2. 四柱神煞引擎僅實作天乙、文昌、桃花、驛馬、華蓋，不能視為完整神煞引擎。桃花、驛馬在年支及日支兩種基準中都排除年柱，需核對所採原典後再定取法，不能只靠解除顯示限制。
3. 老師兩個入口在進階解讀未放行時整塊返回警語，連已核對的日主、四柱、藏干、十神說明也沒有提供。
4. 配對中的紅鸞、五行補強及 AI 增強各自被條件限制；基礎配對仍計算，不是神煞資料向下污染全部計算。
5. 舊共用訊息在基礎驗證失敗時仍聲稱「基礎已核對」。老師 API 尚未讀取本次命盤就使用相同訊息，也不能聲稱該命盤已核對。
6. 古籍總表的版本／著者爭議和五神取法爭議都是真實未解項；不能修改狀態為 VERIFIED 來恢復畫面。
7. 運算進度原本只按欄位存在就勾選神煞、喜用、格局、旺衰與老師解析完成，未核對正式放行條件，會造成先勾選成功再看到無結果的矛盾。現已逐項同步放行狀態，不可用項目不打完成勾，整體也不標為全部完成。
8. 完整專業表的進階分支原本僅檢查進階判讀狀態就列神煞，未單獨檢查神煞資格；现已補上獨立條件，避免未來只解鎖進階判讀便順帶解鎖神煞。

## 本次修復

- 四柱神煞與紅鸞使用獨立主張、狀態及放行條件；缺來源仍保持待核對。
- 神煞欄用短橫線，表下明確說明「暫未提供」且不代表無神煞；不再四次重複工程警語。
- 老師區提供只讀排盤欄位的基礎命盤說明，不使用原先被扣住的 AI 段落、強弱、喜用或運勢結論。未知時辰不顯示時柱。
- 基礎校驗失敗與進階資料未提供，改為不同訊息；老師 API 不對尚未核對的請求宣稱驗證成功。
- 保留進階 API 的後端限制，避免前端看似恢復、後端卻输出未經核對的判讀。
