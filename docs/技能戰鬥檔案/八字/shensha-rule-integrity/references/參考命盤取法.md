# 特星神煞：太極紫微易經派取法（本站自家一派，業主定案 2026-09-27）

本檔是「特星神煞」卡的正式取法，屬本站自家一派「太極紫微易經」：客戶填寫資料 → 八字運算 → 生成紫微斗數 → 有邏輯地衍生特星神煞。業主提供紙本命盤作為標準答案，決定：
1. 整張卡改用紙本取法（桃花、將星、隔角、天德、月德一併改），舊的袁本／神峰取法只留作來源對照；
2. 算出來就顯示，沒有原典頁碼的項目標「＊」並寫明「依本站太極紫微易經派取法，原典頁碼待補」；
3. 來源狀態維持 `PENDING_POOL`（`referenceMethod: true`），**不得**寫成「已通過交叉比對」，原典頁碼逐項補齊後再改為 VERIFIED。

範圍：只限雙命盤頁 `/dual-chart` 的特星神煞卡。八字核心、紫微、其他卡片一律不動。

## 衍生鏈（後端運算，前端只顯示）

```
出生資料
 → 八字四柱（lib/bazi/engine.ts，唯一來源）
 → 紫微命盤（沿用三合一 runZiweiLayer），四柱以 verifyFourPillars 與八字逐字核對
     └ 任一柱不同：停在核對關，神煞不判定，卡片原樣列出「哪一柱、八字是什麼、紫微是什麼」，不自動改任一套
 → 特星神煞（lib/dual-chart-shensha.ts，只讀已核對四柱、日干、十二運）
 → 卡片檢視（lib/dual-chart-shensha-card.ts：每柱命中、待確認、說明文字全部在後端決定）
 → 易經（lib/shensha-iching.ts：沿用三合一 runIChingLayer 起卦；每一個命中的神煞逐項延伸；不寫未登記來源的吉凶）
 → 前端《神煞易經》卡（app/dual-chart/BaziChart.tsx 的 ShenShaCard）只照印
```

## 老師解盤：字有字的意境（業主定案 2026-09-27）

每一個命中的神煞，逐字取姓名學字庫字義作意境參考（`lib/shensha-char-imagery.ts` 的 `SHENSHA_SENSE_PICKS` 為本派選義）。
教育部《重編國語辭典修訂本》授權 CC BY-ND 3.0 TW：只挑義項、以句為單位原文照引、標明出處，不改字、不拼接。
字庫只收前三義項，找不到合適的（將、桃、蓋、五、六）只寫五行，不硬湊。字面意境不是神煞古籍定義，不下吉凶。

## 導師解盤話術（業主定案 2026-09-27）

「每一句話都要有易經老師解盤的概念。」`lib/shensha-teacher-readings.ts` 為 22 個神煞各寫一段本派話術：
本意（整個詞在說什麼）→ 意境（一個看得見的畫面）→ 柱位（本派宮義：年＝根與門面、月＝環境與舞台、日＝自己與枕邊人、時＝出口與晚景）→ 落地（今天可以怎麼做）。
整體再分「福氣／動能／提醒」三類總覽，最後回到生辰卦的行動建議：讀意、讀位、讀卦，三者合看。
範例：外桃花＝牆外的好人緣——異性緣好、外面的貴人多。凶煞照易經心理學「殼與禮物」只講提醒與轉化，不嚇人、不下定論。

## 已知限制

- 取法是從一張紙本反推並與常用排盤表對照，僅證明對這張盤成立；再有紙本命盤時要加進 golden 逐張比對。
- 四柱核對沿用三合一同一道閘（紫微層四柱與八字同源），抓的是資料傳遞錯誤，不是兩套演算法互驗。不要改用 iztro 的 chineseDate 比對：它的月柱依農曆月，節氣前後會誤擋（例：1990-01-01 八字丙子、chineseDate 丁丑）。
