## 現有可證實

- 四柱來自現有八字核心，神煞使用確定性取法；雙命盤的真實接點和定向測試見 [project-map.md](project-map.md)。此技能不另建核心。
- 已有指定版本 `MINGLI_TANYUAN_SHENSHA_V5`、原典/卷頁/規則與部分測例的可追溯鏈。這是所採版本的證據，不等於「唯一權威」或各派共識，也不證預測人生的科學效度。
- `SELECTED_EDITION` 固定採袁樹珊《增訂命理探原》1937訂正版；天乙、文昌、桃花、驛馬、華蓋按所選版本與命中條件輸出，其他版本只作比較說明。空欄表示所選版本下該柱無命中。
- 有工程回歸與API/元件測例；產品通過部分測試不等於全部神煞完成。此批歸檔不改來源登記內的放行狀態。

## 可採用原則

1. 只接可信同源四柱，不補造未知時辰、缺柱或神煞命中。
2. 指定版本、逐條原文定位、確定性取法、獨立期望測例可追溯；適用範圍清楚，不混書補公式。
3. 前端只呈現既有允許結果；AI可解說但不得改命中、柱位、來源、版本或狀態。
4. 改動應有差異理由及對應回歸證據；未測、受限、未命中、來源衝突分開回報。

## 可作未來設計建議（未證實已實作）

- 真實雙人獨立人工覆核及可稽核簽核流程；不能用兩個AI或同人兩次冒充，無簽核不填 reviewer/approved_at。
- 正式規則庫的部署唯讀、版本化變更審批、資產完整性檢查；需先查實際儲存與部署，不虛構資料表。
- 判定輸入/規則/引擎/結果 hash：需明定曆法、時區、精度、早晚子、正規化與依賴版本、排序及編碼，排除時間戳等非判定資料。文件 hash 只證原稿一致，不代表此功能存在。
- 規則/引擎變更時按風險進行影子比對；新舊一致不證正確，差異須解釋。普通文案/歸檔變更不必套完整遷移工程。
