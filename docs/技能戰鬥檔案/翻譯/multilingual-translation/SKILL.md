# 多語翻譯

## 使用範圍

- 網站閱讀語言與獨立翻譯工具是兩個流程，不能用翻譯輸入框冒充全站語言切換。
- 優先支援繁體中文、簡體中文、英文、日文、韓文；只列實際完成並驗證的語言。
- 使用者已明確要求整頁切換：標題、說明、按鈕、表單、驗證訊息、展開內容和動態解說皆須列入，不能以入口卡片的翻譯代表整頁完成。
- 執行 scripts/audit-interface-copy.cjs 產生原始碼文字候選清單；清單包含隱藏區塊及非顯示字串，需逐項分類，不可盲目全域取代。另測資料產生後的動態畫面。
- 網站固定按鈕和提示使用審核過的字典，避免每次開頁都呼叫服務。由客戶選擇語言，不依國籍強制指定。
- 姓名原字、出生資料、四柱、數值、排盤結果及計算骨架不因顯示語言改寫；專有詞提供原文對照。
- 動態內容按需要翻譯，顯示機器翻譯標記，保留切回原文的方式。

## Google 串接

使用者已同意為翻譯使用 Google。這不代表重新啟用易經老師的 Google 提供者，也不代表購買或提高付費額度。
金鑰留在後端；技能保存串接規則與官方索引，不能當作離線模型或所有內容的授權證明。
先以不含客戶資料的短句驗證服務，確認可用才宣告翻譯功能完成。
限制請求大小、頻率與等待時間；額度不足、離線或空回應應顯示未完成並保留原文，不能用原文假裝譯文。
客戶原文與譯文預設不長期保存。官方資料參考：https://ai.google.dev/gemini-api/docs/text-generation

## 字幕文字

先支援貼上文字及 SRT 匯入；不宣稱可以聽取或翻譯整部影片。
使用 lib/translation-content.ts 保留字幕編號、順序與時間，只送字幕文字翻譯。
逐段核對結果數量，失敗不得輸出缺段的成功檔案；提供原文與譯文對照。

## 驗收

驗證實際翻譯與錯誤回應、字幕時間保持、手機長文換行、LINE 複製與下載備援。
本機、提交、推送、部署及真機驗收分別回報，不以其中一步代表全部完成。
