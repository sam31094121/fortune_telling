# 開源翻譯來源盤點

查核日期：2026-09-25。此文件收納來源索引及部署條件，不代表已安裝模型或已完成翻譯服務。

## 英文優先候選

Helsinki-NLP / opus-mt-zh-en：中文轉英文模型，由赫爾辛基大學語言技術研究團隊發佈。

- 官方模型卡：https://huggingface.co/Helsinki-NLP/opus-mt-zh-en
- 該模型卡目前標示 CC-BY-4.0，使用時須保留來源與署名並依授權條件處理。不能將其他方向的模型授權套用到本模型。
- 需要模型權重、分詞器及推論環境；只下載說明文件不會產生翻譯能力。
- 僅對應中文到英文，其他語言需各自驗證模型、授權及品質。
- 上線前以合成命理術語、長文、數字保留、字幕分段進行品質評估；不得把模型輸出當成原始排盤資料。

## 可自行部署的翻譯服務

LibreTranslate：以 Argos Translate 為引擎，可自行部署，並非 Google 的離線副本。

- 官方文件：https://docs.libretranslate.com/
- 安裝指南：https://docs.libretranslate.com/guides/installation/
- 服務 API 授權說明：https://docs.libretranslate.com/api/ （AGPL-3.0）
- 官方代管 API 金鑰說明：https://docs.libretranslate.com/guides/manage_api_keys/
- 自行部署仍需要運算資源、模型、維護及服務可用性；官方代管 API 並非免費無限制。
- 本機有服務不代表 Vercel 正式網站可存取，不可使用 localhost 作為正式翻譯端點。
