# 寶石捷連線・敗部復活（局中逆轉）

版本：v5，2026-11-18（台北）。業主已授權定案數值並實作；本輪實作與針對性驗收完成；全站健康64/66，業主已明確批准僅本次兩項既有來源失敗的提交／推送豁免。數值唯一機器來源為同目錄「敗部復活.json」。

## 一、核心定義與範圍

「敗部復活」是玩法名稱，意思是同一局尚未結束時扭轉劣勢，**不是死後復活**。角色生命歸零就保持倒下；全隊歸零依既有規則判敗，不重開該局、不把敗局改成勝局。較早對話中「倒下再活」的解讀作廢，以本定義為準。

只適用寶石捷連線 `/beast-game/match3-hard`（hard45），本人與親友採相同戰鬥規則、各自獨立進度。不改其他遊戲、命理卡片、原卡數值、永久培養、收藏獎勵或押卡契約。總入口為 `docs/beast-game-skill.md`；沿用原戰鬥核心。

## 二、局中逆轉：觸發、效果、期限

1. 對局仍在進行、敵方仍存活、我方至少一位存活，且我方全隊目前生命合計不高於原全隊生命上限合計的30%，定義為可獲援助的逆境。
2. 在有效連線開始或本輪結算後檢查，一局最多觸發一次。無效拖曳不領援助；不根據畫面或預測文案判定快輸。
3. 只替存活角色回復各自生命上限的35%，向下取整且不超上限；倒下角色保持零血。
4. 同時給予接下來三次有效寶珠或法寶動作攻擊增強50%。在動作前觸發時，本次計為第一次；本輪結束才觸發時，從下次開始。無效拖曳、開說明或點選目標不消耗次數。
5. 不延長戰鬥演出；以既有血條、實補數字及簡短狀態提示說明「逆境奮起」，讓玩家知道是技能作用。

## 三、同關第三次挑戰：破陣援擊

- 同一關連續兩次完整敗局後，第三次挑戰開場提供五次「破陣援擊」。勝利過關後清零；退出、未完成、重送請求與重載不增加敗局次數，也不重置當局已用次數。
- 每次有效連線後，若我方仍有人存活、敵方仍有可攻擊目標，自動消耗一次援擊。傷害額為該目標當下生命加護盾，以既有傷害處理實際吸收護盾及扣血；只打當下可出戰的一個目標，不跨過末位神獸的出場限制。
- 正常攻擊已清場時不消耗援擊，不直接寫入勝利旗標。援擊紀錄包含目標、生命前後、護盾吸收、實扣及剩餘次數。
- 這是公開的第三次援助與可驗證過關路徑，**不是死亡後仍保證勝利**。後續澄清的「死了就死了」優先：全隊歸零依原規則判敗，沒有操作、無效連線或尚未完成對局不能算贏。不得宣稱任何操作都必勝。
- 本人從後端保存的同關敗局計數取得資格；親友沿既有分頁簽章狀態保存。前端提供的敗局次數不能直接授權援擊；舊存檔未記錄的敗局不猜補。

## 四、寶珠與武器增強

逆境奮起的1.5倍僅作用於既有寶珠攻擊與法寶傷害計算，仍經原本屬性、護盾、傷害上限及終局處理。原技能附加效果、法寶數量、能量成本與永久攻擊值不改。法寶多段攻擊仍算一次法寶使用，不把三段誤算成三次使用。

寶石捷連線的五元素寶器原傷害倍率統一乘2，保留原屬性與各寶器功能；逆境增強再乘1.5。八面同元素盾合成的第五階稀有寶器另有明示規則：本次對選定可攻擊目標的實扣生命，至少為該目標生命上限50%（向上取整），剩餘不足則扣到零；護盾吸收另外記錄，不充當扣血。原攻擊已超過下限時不重複扣半血。使用時全體存活隊友各補生命上限50%（向下取整、缺血封頂），零血不復活；消耗原有一件庫存，由玩家點擊觸發，未取得寶器不可施放。這是2026-11-18業主追加的八盾稀有性規則，取代先前「不另立半血規則」的草稿。

## 五、連線補血：兩條清楚分開

### A. 原有相生補血（保留）

至少三格同色珠有效消除，按實際格數每格回復受益隊友生命上限1%；每位受益者每回合累計最多10%，向下取整。不按數字珠儲存威力放大補血。有效掉落消除組亦計入同回合上限。

| 消除元素 | 受益隊友元素 |
|---|---|
| 空 | 水 |
| 水 | 風 |
| 風 | 火 |
| 火 | 地 |
| 地 | 空 |

只補存活、受傷且屬性相符者；不超上限、不復活。來源為既有 `五行盾牌.json`、`element-support.ts` 與 `resolve-turn.ts`。

### B. 七顆成盾、同元素補血（新增）

- 沿原後端成盾資格：有效連線累計威力達七，或有效自然掉落形成新盾牌。數字珠的累計方式沿原核心，不另改生成規則。
- 形成哪種元素的盾牌，就替存活的同元素隊友各回復生命上限10%，按缺血量封頂、向下取整；每位角色每回合成盾補血最多一次。
- 同回合多個同元素新盾不重複加補；一般相生補血與成盾補血是不同來源，可各自適用並分別封頂，不超生命上限。
- 既有同色盾轉換、五色整盤升盾與單純持有盾牌不算新成盾補血，防止轉換整盤無限回血。既有四色護陣治療維持原規則，不混計。
- 例：水屬性角色目前600／1000，形成水盾可實補100至700；若它已倒下則維持0。水珠一般相生補的是風隊友，兩者不能接錯。

前端顯示後端的受益隊友、實補與生命前後值；若隨後反擊，分清「先補、再扣」，不只顯示最後血量。業主反映補血不見了，需以實際頁面確認是否原本提示只藏在說明內；不能僅憑程式存在聲稱客戶看得到。

## 六、第五、六關起的挑戰與速度

- 第五關沿既有五顆攻擊門檻，第六關沿既有六顆；第五關起敵方生命在原關卡基準上乘1.10、攻擊乘1.05。第八關以後原關卡成長與單一末位神獸規則保留。

## 七、後端結算順序與保存

1. 核對本人後端戰局或親友簽章及本次操作，重送沿原去重規則。
2. 驗證連線；符合逆境時先處理存活者援助，再沿原連線、技能與攻擊規則結算。
3. 計算相生補血與新成盾同元素補血，依來源記錄實補，不重複入帳。
4. 處理本次符合資格的破陣援擊，再沿既有敵方反擊順序結算。
5. 若結算後仍有存活隊友且首次達逆境條件，可觸發該局唯一援助；全隊歸零不可觸發。
6. 用真實終局判斷勝負，原子保存戰局、救援次數、同關敗局／勝利進度及原有獎勵收據。
7. 前端只呈現同份回應，不自算血量、援助資格或勝負。
