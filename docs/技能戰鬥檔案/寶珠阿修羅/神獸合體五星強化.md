# 神獸合體升星技能檔案

2026-11-18 業主指定新版合體規則，現行採用v4五星比例實作，驗證證據見 `reports/five-star-entry-2026-11-18/`。日後此功能的材料、升星與攻擊調整先登記本技能檔，再同步後端與前端。與「敗部復活／局中逆轉」分開；不是關卡難度五星制。

## 現行 v4：五星比例平衡（業主追加定案）

業主指出原始攻擊七十多增至五千多不成比例，明確要求立即改用五星比例計算。本節取代下方v3逐張累加攻擊及傳承條款；材料消耗、同屬性／相生優勢與五星張數仍保留。

- 普通材料每星增加原始攻擊10%；同屬性或材料相生給目標之材料，每星對應增量為15%。混合材料按各次實際比例累積，五星合計介於50%與75%。
- 每星內依該星所需張數分攤；使用精確整數成長單位保存小數進度。材料多寡仍計實際張數，單張未湊到一點攻擊時進度保留，不四捨五入成每張至少加一點。
- 比例一律乘該遊戲的原始攻擊，不乘已強化攻擊；不複利，也不將材料原始攻擊或已培養攻擊再平加、傳承進戰鬥。寶珠與神獸戰鬥原始攻擊不同，各自套同一成長比例。
- 青龍原始寶珠攻擊74／神獸戰鬥43：普通材料滿五星為111／64；全部同屬性或相生滿五星為129／75（整數無條件捨去）。滿五星不新增技能、不提高生命、不保證必勝。
- 原v1/v2/v3收據保留，既有吃卡張數不歸零。後端按已存張數與真實材料收據投影成長比例；沒有材料證據的部分按普通比例，不猜相生。舊平加數值留作歷史紀錄，停止直接作為新戰局攻擊。讀取不寫入客戶資料；下一次合法合體時保存比例及歷史值。
- 已開始的戰局保留開局快照，不中途換數值；新開戰、合體預覽與卡庫顯示均採同一比例。對手生命、攻擊與策略沒有因本次升星另行加碼。
- 驗收見 reports/five-star-balance-2026-11-18；測試須包含實際對手行動，不能只用升星成功代替平衡驗證。

## 歷史 v3 操作與加成（攻擊部分已由v4取代）

1. 玩家先點要變強的神獸，再選要吃掉的材料，可一次選多張，確認前顯示批次張數、真實攻擊前後及星級進度。
2. 只有玩家確認後才消耗所選副本；每消耗一張，目標升星計數增加一張。同屬性或相生不折抵張數、不一張算兩張。
3. 新操作取消舊同宿／所屬四象材料限制，以及50%攻擊加成上限。星級封頂仍為四大神獸1000張、成獸500張；已明確確認四星分別累計500／250，再吃500／250滿五星。
4. 基本增量沿材料原始攻擊除10取整、至少1。同屬性或材料元素相生給目標時，基本增量乘1.5並向上取整；兩種資格不重複乘。原成獸材料已累積加成的50%傳承保留，與基本增量分開記錄。這是本次暫行平衡值，不冒充自然定律。
5. 確認前不得自動選材料或送出。可加入目前可用的全部材料，仍受五星剩餘張數及原材料保護約束；不能把「全部可吃」解讀成可吃掉目標、鎖定主力或戰鬥占用副本。
6. 舊版只保留歷史收據重播用途，新操作使用v3；不刪客戶收藏、舊合體紀錄或已存在的攻擊加成。
