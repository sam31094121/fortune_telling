# 神獸合體升星技能檔案

2026-11-18 業主指定新版合體規則，採用v3實作，驗證證據見 `reports/five-star-entry-2026-11-18/`。日後此功能的材料、升星與攻擊調整先登記本技能檔，再同步後端與前端。與「敗部復活／局中逆轉」分開；不是關卡難度五星制。

## 權威實作

- `lib/beast-game/cultivation-rules.ts`：v3元素增量及歷史v2參數、每星張數、累計門檻。
- `lib/beast-game/cultivation.ts`、`cultivation-transaction.ts`：合法合體、材料消耗、保護及交易去重。
- `lib/beast-game/cultivation-view.ts`：後端輸出真實星級、下一星所需張數、攻擊值及未完成戰局入口。
- `components/battlefield/CardStarBar.tsx`：只顯示後端的五星進度與加成。

四大神獸最後一星需要500張，前四星合計500張。幼子不是升星目標；新版不再限制材料卡種對應；可使用其他已持有副本，目標本身與受保護材料仍不可消耗。星級按實際已消耗材料張數累計，不憑空補星，不把試用神獸當成已收藏副本。

## 新版操作與加成（本輪定案）

1. 玩家先點要變強的神獸，再選要吃掉的材料，可一次選多張，確認前顯示批次張數、真實攻擊前後及星級進度。
2. 只有玩家確認後才消耗所選副本；每消耗一張，目標升星計數增加一張。同屬性或相生不折抵張數、不一張算兩張。
3. 新操作取消舊同宿／所屬四象材料限制，以及50%攻擊加成上限。星級封頂仍為四大神獸1000張、成獸500張；已明確確認四星分別累計500／250，再吃500／250滿五星。
4. 基本增量沿材料原始攻擊除10取整、至少1。同屬性或材料元素相生給目標時，基本增量乘1.5並向上取整；兩種資格不重複乘。原成獸材料已累積加成的50%傳承保留，與基本增量分開記錄。這是本次暫行平衡值，不冒充自然定律。
5. 確認前不得自動選材料或送出。可加入目前可用的全部材料，仍受五星剩餘張數及原材料保護約束；不能把「全部可吃」解讀成可吃掉目標、鎖定主力或戰鬥占用副本。
6. 舊版只保留歷史收據重播用途，新操作使用v3；不刪客戶收藏、舊合體紀錄或已存在的攻擊加成。

## 舊版界線

v1／v2舊收據依原版本重播，原50%上限與材料對應不再限制新v3操作。舊數值不扣回。五星門檻與原卡面不改，前端只顯示後端結果。

## 畫面入口與本次修正

星宿神獸頁的四象縮圖與上箭頭已連到 `/beast-game/four-beasts`；寶珠本人選卡頁亦有共同卡庫合體面板。實際查核已讀到卡庫、星級及下一星張數，不能寫成「整套未推送」。

此次可重現阻擋：有未完成戰局時，強化卡片停用；原介面僅提供結束戰局，缺少直接返回原戰局的選項。

修正：後端按保存的戰局類型提供返回位置，圖示版新增返回戰鬥圖示，文字版新增「返回原戰局」。戰鬥中允許查看目標，但材料及確認仍停用，不能消耗。玩家可先回原戰局完成或自行選擇結束，再回來強化；返回連結本身不提交結算、不發獎、不消耗材料、不解除戰局。

頂列四大神獸改為可點選目標；未收藏時顯示原因，不自動發卡。已選目標下方顯示材料，可單點、長按、加入可用材料或清空選擇；最後一次確認才結算。保留卡圖與卡面外五星，新增簡短步驟文字。五星封頂仍可查看，但不能餵食。寶珠與神獸戰鬥入口共用此操作。

## 驗收界線

需核對寶珠兩模式及神獸卡片戰的返回位置、沒有戰局不顯示入口、未知戰局不猜地址；驗證原升星與材料保護回歸。不得以開啟畫面代替實際合體成功，也不使用客戶材料做測試。
