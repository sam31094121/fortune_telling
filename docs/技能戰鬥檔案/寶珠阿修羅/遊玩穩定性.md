# 寶石捷連線：遊玩穩定性驗收

本輪業主授權僅細修穩定性與流暢度，不改玩法、傷害、獎勵、掉珠數量、碰撞路徑或儀式播放時間。

## 必須實跑的檢查

- `test:beast-drop-render-stability`：390px 瀏覽器手機模擬，以隔離測試戰局連十一盾得到四珠，涵蓋一般與減少動態模式。每顆珠子的出生及可見狀態寫入最多三次，不得每幀重寫相同值；接住才計數，獎勵不重複，手動攻擊仍可用。失敗納入健康檢查，不得只以頁面 HTTP 200 代替。
- `test:beast-match3-replay`：實際連線、後端確認、慢回應與校正、操作恢復，以及既有離場取消待執行動作與聲音回歸。逐項保留實跑結果，未執行的情境不得記為通過。
- `test:beast-layout-stability`：短螢幕靜止與捲軸切換不得持續位移。
- 持續遊玩驗收需另記連續回合數、裝置尺寸、耗時與錯誤；短流程通過不代表長時間或所有實體裝置永不卡頓。大量掉珠的既定等待不等同卡死，必須確認計數前進與結束後能再操作。

## 三裝置共同驗收（業主指定）

- 手機：390px 一般與減少動態模式，另由既有回歸覆蓋320px窄屏。
- 平板：768px 實際連線回歸，核對放手回饋、消珠補珠、恢復操作、錯誤紀錄。
- 筆電：1440px 實際連線回歸，核對相同流程；需要判斷排版時另測1366×768實際視窗，不以縮小截圖代替。
- 三種裝置逐項記錄通過或失敗；上述均為瀏覽器尺寸模擬，不能稱為實體裝置測試。完整遊戲健康檢查須含 `test:beast-match3-replay` 三裝置流程、新增掉珠更新次數檢查，以及既有防抖檢查。
- 版面核對維持已核定規格：同裝置一至五隻連線寶珠大小一致、卡片按剩餘空間等比例放大、武器配對、不重疊或持續位移；本輪穩定性細修不重新設計版面。
