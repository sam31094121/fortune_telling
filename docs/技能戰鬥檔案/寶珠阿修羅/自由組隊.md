# 寶石捷連線自由組隊

2026-11-19 業主指定，只適用 hard45 寶石捷連線。

- 玩家保留親選主角，可額外選零至四位夥伴，合計一至五隻；不自動補卡、不強制湊滿。零隻、超過五隻、重複、未解鎖卡與缺少主角都不得開戰。
- 選卡、開戰後端驗證與存檔保持同一人數契約；對手仍依既有關卡五隻陣容，不改傷害、反擊、掉珠或獎勵。
- 一隻使用既有大卡與接取範圍；兩至四隻依實際數量置中、等比例排滿，五隻維持既有排列。少人不留假的空卡位，不拉伸卡圖。
- 只做一至五隻開場手機排列驗收，不替業主操作攻擊或消耗收藏。相關證據見 reports/beast-game/party-size-2026-11-19。

同一視窗尺寸下，選擇一至五隻不得改變連線盤與盤內寶珠尺寸、比例；神獸只在盤面以外的可用空間按原比例放大。武器欄數、欄寬及間距與所屬神獸對齊。驗收須逐一比對盤面寬高，不以無重疊代替尺寸一致。

多隻隊伍的能量攻擊寶珠居中放在本體卡片下、所屬武器上；預留固定按鈕空間，滿能量顯示時不推動盤面。單隻大卡的左右入口維持原樣。短屏空間不足允許捲動，不壓縮寶珠盤或重疊按鈕。

單隻大卡與左右武器／攻擊寶珠至少保留10px實體邊界間距，避免光暈貼住卡片；僅限制大卡放大上限，寶珠盤不變。
