# 九盾法珠掉落（2026-11-18 業主指定）

狀態：本機規則與瀏覽器手機尺寸驗收完成；正式部署另依提交版本核對。

- 僅寶石捷連線本輪授權；前八顆盾牌沿用既有規則。
- 一次有效連線全部為同元素盾牌且達九顆時，產生「實際連線盾牌數 − 8」顆法珠：九顆一珠、十顆兩珠、十一顆三珠。儲存威力不當作實體盾牌數。
- 使用現有五元素寶珠素材。各珠依連續重力、碰撞、反彈及能量衰減軌跡掉落；不得先挑受益神獸再造動畫吸附。
- 每珠獨立判定。落入存活神獸的接取區才取得武器並發光，之後由玩家手動使用。空格、倒下的位置、最後大卡片接取區之外均落空消失，不轉送。
- 接到法珠的存活神獸生命補至自身上限，攻擊能量蓄至既有上限；其對應五元素武器增加一顆。實補量記錄在回合結果；重複接珠不可超補。不自動施放；強化攻擊依下一條規則。隨後敵方仍依正常回合反擊，故回合結束血量可能再次下降。
- 強化寶珠攻擊：每接一珠增加一次「神獸卡上寶珠攻擊」強化資格，手動使用滿能量攻擊時消耗一次，保證目標實扣至少最大生命的 50%（不足時只扣剩餘生命，護盾不抵扣這個實扣生命門檻）。不改底下武器傷害、不自動攻擊、不提高永久攻擊值。目標仍存活時，其下一次實際反擊被封鎖，實扣為零，消耗封鎖後恢復原攻擊；不永久歸零，不跨目標轉送。重複命中只保留下一次封鎖，不堆疊永久沉默。
- 顆數不另設獎勵上限；只受本次盤面真實盾牌數限制。目前 56 格盤面至多連 56 盾，故一次最多自然產生 48 珠，並非另加的獎勵封頂。
- 後端提供軌跡、碰撞時點、落點、接取對象、實際入庫與去重收據；前端只播放同一結果。保存失敗不可宣稱已取得；重試不可多領。
- 音效與實際碰撞、落定同步，遵守既有靜音；切頁與離場停止，減少動態不改實際結果。
- 業主追加：掉落演出以同一路徑放慢至原時長的 1.6 倍，落定發光停留 550 毫秒；一般連線補珠速度不變。
- 原手機版面工程繼續：最後大卡片按比例完整呈現、武器和血條移到側邊，不擠小寶珠盤、不推移盤面。

驗收：九／十／十一盾數量、八盾回歸、非同色與混普通珠不觸發、逐珠落空／接取、倒下不領、同收據不重發、保存重開一致、手機短屏不跳動、音畫同步及可恢復操作。
