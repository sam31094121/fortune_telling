# 二十八星宿神獸：初相／覺醒視覺規範

## 卡牌層級

每一隻神獸有兩個固定層級：

- **初相（Base）**：星宿力量尚未完全顯現。動物本體辨識最優先，氣質安靜、靈性初醒。
- **覺醒（Awakened）**：現有的 28 張正式神獸卡。完整星紋、季節異象、古金細工與神獸位階都已顯現。

初相不可改變物種：狼仍是狼、烏鴉仍是烏鴉、參水猿仍是無尾猿。覺醒感來自星宿力量與四象部位的顯化，而非改造成另一種動物或人形角色。

## 初相卡共同規則

1. 卡框、四角飾紋、上下中央飾件與卡牌比例與覺醒卡相同。
2. 主體置於中央但尺寸較覺醒卡小約一級，姿態以停立、棲息、行走、蹲伏為主。
3. 每張只能有一個微弱的「本命徵兆」：星點、淡符印、眼眸微光、單一羽紋或小範圍靈氣。
4. 不使用滿身符紋、完整鎧甲、巨大光環、戰鬥爆發、跨框特效或過多星象。
5. 保持礦物顏料、古金細工、東方玄幻收藏卡質感；不含任何文字、Logo、浮水印或 UI。

## 四季初相底板方向

初相底板不是現有覺醒神域的低飽和或低亮度版本。兩者必須是同一季節、同一套卡框語言下的**不同地點**：初相位於人間邊境，覺醒位於四象星宿神域。初相的「弱」指星象、地景規模與超自然異象較低，不指顏色、質感或完成度較低。

| 季節／四象 | 初相世界 | 覺醒世界（現有） | 初相核心色 |
|---|---|---|---|
| 春／蒼龍 | 林間石橋、翠綠丘陵、竹林、淺溪與粉櫻 | 完整生長異象與星盤 | 嫩綠、霧青、淡金 |
| 夏／朱雀 | 荷塘棧道、竹影、小石燈、窄瀑與暖風 | 強烈日火、瀑布、荷塘與星光 | 青碧、荷粉、暖金 |
| 秋／白虎 | 楓林山徑、石板小溪、矮石燈與殘月 | 滿月山谷、金色星盤與戰場感 | 琥珀、朱紅、月銀 |
| 冬／玄武 | 雪松村橋、半結冰溪流、遠村燈火與冷月 | 冰晶、雪嶺、完整玄武天象 | 冰藍、雪白、冷金 |

## 底板不變項

- 僅製作四張底板：每個季節一張，供同季七隻初相神獸共用。
- 初相底板必須保留現有季節卡系統的外側金框、黑色外邊、四角飾紋及上下中央飾件。
- 中央保留足夠留白，使初相神獸不壓迫背景與卡框。
- 底板本身不含神獸、名稱、文字、Logo 或浮水印。
