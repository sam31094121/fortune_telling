# 站立指令檔｜開啟／健康檢查

> 此檔與技能「右側螢幕連結健康檢查」同步，供以後指令一律遵守。

## 一律要做
1. **連結**：對目標服務做真實健康檢查（端點／API／共用檔案）
2. **開啟右手邊螢幕**：在我的電腦桌面瀏覽器顯示看板或目標頁
3. **螢幕箭頭**：畫面上必須有流程箭頭  
   `後端運算 → 結果寫入看板 → 右側螢幕顯示給你修`
4. **截圖交給使用者**：不可只回文字

## 觸發詞
- 開啟
- 健康檢查
- 啟動=健康檢查
- 要看連結／準確性／精準維修

## 原則
- 後端先算，前端螢幕證據後顯示
- 不捏造檢查結果
- 若連不到使用者本機區網，要明說，不可假裝嵌入成功
