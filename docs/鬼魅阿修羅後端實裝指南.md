## 🔧 四層運算引擎實裝清單

### 層級 1：八字命盤（核心基礎）

**檔案：** `/lib/bazi/engine.ts`

**職責：**
- 接收：生辰日期 + 時間
- 計算：四柱干支（年月日時）
- 驗證：排盤邏輯正確性
- 輸出：BaziCore 結構

**關鍵函式：**
```typescript
createBaziCore(birthDate: string, birthTime?: string): BaziCore
```

**返回值：**
```typescript
{
  year: "甲寅",    // 年柱
  month: "庚午",   // 月柱（含節氣判斷）
  day: "甲辰",     // 日柱
  hour: "丙寅"     // 時柱
}
```

**實裝要點：**
- ⚠️ 小暑日期判斷（7/7 前後月柱變化）
- ⚠️ 五虎遁推算（年干配月）
- ⚠️ 時辰對應地支（子時 23:00-01:00）
- 預設測試數據：`1974-07-02 03:30 → 甲寅/庚午/甲辰/丙寅`

---

### 層級 2：紫微斗數排盤

**檔案：** `/lib/ziwei/engine.ts`

**職責：**
- 接收：BaziCore（四柱）
- 計算：十二宮星盤排列
- 驗證：四柱與八字一致
- 輸出：ZiweiChart 結構

**關鍵函式：**
```typescript
calculateZiwei(bazi: BaziCore): ZiweiChart
```

**返回值：**
```typescript
{
  palaces: [
    {
      name: "命宮",
      mainStar: "紫微",
      secondaryStars: ["左輔", "右弼"],
      yearlyInfluence: "今年流年提示..."
    },
    // ... 11 個宮位
  ],
  analysis: "紫微整體解讀話術..."
}
```

**驗證邏輯（必須）：**
```typescript
if (bazi.year !== ziwei.bazi.year) throw new Error('四柱年柱不一致');
if (bazi.month !== ziwei.bazi.month) throw new Error('四柱月柱不一致');
if (bazi.day !== ziwei.bazi.day) throw new Error('四柱日柱不一致');
if (bazi.hour !== ziwei.bazi.hour) throw new Error('四柱時柱不一致');
```

---

### 層級 3：特星神煞運算

**檔案：** `/lib/iching-shensha-combos.ts`

**職責：**
- 接收：BaziCore（四柱）
- 計算：65 項神煞（含洋蔥心理學層）
- 組合：本派 13 條組合規則
- 輸出：ShenShaItem[] + combo 話術

**關鍵函式：**
```typescript
calculateIChingShenSha(bazi: BaziCore): {
  items: ShenShaItem[],
  combo: string,
  flowYear: {
    current: string,
    next?: string
  }
}
```

**ShenShaItem 結構：**
```typescript
{
  id: "external-peach",
  name: "外桃花",
  category: "吉星",
  pillar: "日柱",
  description: "後端產出的話術...",
  psychology: {
    shell: "表層意義",
    heart: "內層意義",
    gift: "轉化禮物"
  }
}
```

**實裝要點：**
- 65 項神煞完整列表（含第八批）
- 洋蔥心理學三層剝殼
- 流年神煞：甲「流年沖」+ 乙「歲神轉移」
- 組合規則：13 條（同柱或整盤）

---

### 層級 4：易經卜卦 + 融會貫通

**檔案：** `/lib/iching-layer.ts`

**職責：**
- 接收：BaziCore + ShenSha
- 計算：易經卦象（1-64）
- 融合：神煞與卦象的連結
- 輸出：IChingResult + 話術

**關鍵函式：**
```typescript
runIChingLayer(bazi: BaziCore, shensha: ShenSha): {
  hexagram: number,
  name: string,
  judgment: string,     // 後端產出
  guidance: string,     // 後端產出
  psychology: string,   // 後端產出
  shenShaConnection: string
}
```

**實裝邏輯：**
1. 根據日主和四柱生成卦象
2. 查詢易經原典解讀
3. 關聯到當前人生階段的神煞
4. 融合洋蔥心理學視角

## 🎯 話術生成引擎

**檔案：** `/lib/ghost-asura-narrative-engine.ts`

**五大話術產生點：**

| 話術 | 產生函式 | 來源 | 責任 |
|------|---------|------|------|
| `bazi.analysis` | `generateBaziNarrative()` | 八字運算 | 日主性格 + 十神 |
| `ziwei.chart.analysis` | `generateZiweiNarrative()` | 紫微宮位 | 命宮特質 + 流年 |
| `shensha.combo` | `generateShenShaOnionNarrative()` | 神煞組合 | 整盤洞見 |
| `iching.*.judgment/guidance` | `generateIChingNarrative()` | 卦象爻位 | 易經解讀 |
| `teacherReading.*` | `generateFullTeacherReading()` | 綜合以上 | 老師人設 |

**重點：** 所有話術都由後端產出，前端只照印。

## 🆘 常見問題

### Q: 四柱驗證失敗怎麼辦？

**A:** 停止所有後續流程，回傳 422 錯誤：
```json
{
  "code": "VERIFICATION_FAILED",
  "message": "四柱驗證失敗，無法生成完整命盤",
  "details": {
    "baziYear": "甲寅",
    "ziweiYear": "乙卯"
  }
}
```

不允許自動修正——保持誠實。

### Q: 話術要不要做多語言？

**A:** 暫不實裝。所有話術先用繁體中文，後端決定。前端零翻譯邏輯。

### Q: API 回應太大會不會影響性能？

**A:** 預期 150-250 KB（gzip 後）。可接受。如需優化：
1. 只回傳必需的神煞（不回傳全部 65 項）
2. 話術縮短為摘要 + 詳細詳情分頁

### Q: 生日時間不精確怎麼辦？

**A:** 提示使用者，但照常計算。註記在卡片中：
```
「本命盤基於時辰 03:30 計算，如實際時間不同，可能影響準度」
```
