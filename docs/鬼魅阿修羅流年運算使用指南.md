# 鬼魅阿修羅 - 流年運算使用指南

## 📋 完整流程

```
前端提交資料
  ↓
POST /api/ghost-asura/timeline
  ├─ name: "王小明"
  ├─ birthDate: "1974-07-02"
  └─ dayMasterElement: "木" (可選)
  ↓
後端計算
  ├─ calculateGhostAsuraTimeline()
  ├─ 計算過去年份的干支、五行、主星、幸運指數
  ├─ 計算現在年份的干支、五行、主星、幸運指數
  ├─ 計算未來年份的干支、五行、主星、幸運指數
  ├─ 計算整體趨勢（上升/下降/循環）
  └─ 回傳 GhostAsuraTimelineResponse
  ↓
前端接收
  ├─ renderTimelineWithAsuraVoice()
  ├─ 調用 lib/asura-wording.ts 話術庫
  ├─ 生成 TimelineRenderedText（完整話術）
  └─ 用 GhostAsuraTimelineCard 直接渲染
```

## 🔧 後端實裝

### 流年計算引擎（lib/ghost-asura-flow-year-engine.ts）

**核心函式：**

```typescript
calculateGhostAsuraTimeline(
  userName: string,
  birthDate: string,
  dayMasterElement?: string
): Promise<GhostAsuraTimelineResponse>
```

**計算邏輯：**

1. **年干支計算**
   - 基於西元年份推算天干地支
   - 天干循環：甲乙丙丁戊己庚辛壬癸（10年）
   - 地支循環：子丑寅卯辰巳午未申酉戌亥（12年）

2. **五行確定**
   - 天干五行：甲乙木 / 丙丁火 / 戊己土 / 庚辛金 / 壬癸水
   - 地支五行：子水 / 丑土 / 寅木 / 卯木 / 辰土 / 巳火 / 午火 / 未土 / 申金 / 酉金 / 戌土 / 亥水
   - 主導元素以天干為主

3. **幸運指數計算**
   - 基於日主五行 vs 年主五行的生克關係
   - 生克表：木生火、火生土、土生金、金生水、水生木
   - 範圍：0-100 分
   - 含隨機波動以模擬現實不確定性

4. **主星確定**
   - 根據天干特性對應
   - 甲：貴人、乙：柔和、丙：熱情、丁：細膩、戊：務實
   - 己：靈活、庚：剛正、辛：優雅、壬：聰慧、癸：沉靜

5. **視覺配置**
   - 過去：綠色（成長）/ 橙色（挑戰）/ 預設（平穩）
   - 現在：紅色（戰鬥）
   - 未來：金色（機遇）/ 預設（發展）
   - Icon：📜 / 😔 / 🔥 / ✨ / 🌟

## 🎨 前端實裝

### 使用客戶端鉤子

```tsx
import { useGhostAsuraTimeline } from '@/lib/hooks/useGhostAsuraTimeline';
import GhostAsuraTimelineCard from '@/components/GhostAsuraTimelineCard';

export default function TimelinePage() {
  const { data, isLoading, error, calculate } = useGhostAsuraTimeline({
    onSuccess: (result) => {
      console.log('流年計算成功：', result);
    },
    onError: (err) => {
      console.error('流年計算失敗：', err);
    },
  });

  const handleCalculate = async () => {
    try {
      await calculate({
        name: '王小明',
        birthDate: '1974-07-02',
        dayMasterElement: '木',
      });
    } catch (err) {
      console.error(err);
    }
  };

  return (
    <div>
      <button onClick={handleCalculate} disabled={isLoading}>
        {isLoading ? '計算中...' : '計算流年'}
      </button>

      {error && <div>錯誤：{error.message}</div>}

      {data && <GhostAsuraTimelineCard data={data} />}
    </div>
  );
}
```

### 卡片組件（已提供）

前端自動調用：
1. `renderTimelineWithAsuraVoice(data)` → 生成話術
2. `GhostAsuraTimelineCard` → 直接渲染

**零邏輯保證：**
- ✅ 前端只接收計算結果
- ✅ 前端只調用話術生成器
- ✅ 前端只照印所有文案
- ❌ 前端禁止修改或拼接
- ❌ 前端禁止根據數據決定邏輯

## 📊 計算示例

### 例子 1：日主為木

```
輸入：
  name: "王小明"
  birthDate: "1974-07-02"
  dayMasterElement: "木"

計算過程：
  ① 過去（2024年）
     - 年干支：甲辰
     - 天干五行：甲 = 木
     - 日主 vs 年主：木 vs 木 = 生克表 70 分
     - 隨機波動 ±10 = 60-80 分

  ② 現在（2025年）
     - 年干支：乙巳
     - 天干五行：乙 = 木
     - 日主 vs 年主：木 vs 火 = 生克表 85 分
     - 隨機波動 ±10 = 75-95 分

  ③ 未來（2026年）
     - 年干支：丙午
     - 天干五行：丙 = 火
     - 日主 vs 年主：木 vs 火 = 生克表 85 分
     - 隨機波動 ±10 = 75-95 分

  ④ 整體趨勢
     - 過去：60-80 → 現在：75-95 → 未來：75-95
     - 趨勢：上升期 → 突破期
```
