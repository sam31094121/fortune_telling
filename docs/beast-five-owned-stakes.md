# 五張收藏押注

- 試用牌庫的 60 種神獸只供戰鬥，不能直接作為收藏押注。
- 完成遊戲首次贈送的 28 張幼子，成功入庫後才可選入。
- 每場選五個不同的收藏副本編號；同名卡有多個實際副本可以分別選。
- 第一張沿用自動單挑；另外四張也是押注。輸則精準移除五個編號，贏則保留五張並額外加一張，平手保留五張。
- 押注前重新讀取收藏並鎖定；結算核對全部五個編號，收據防止重複扣除或發獎。
- 目前收藏保存在瀏覽器。此版不提供伺服器帳號所有權、防竄改或跨裝置同步保證。
