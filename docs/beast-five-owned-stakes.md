# 1～5 張收藏押注與引導

- 60 種戰鬥試用牌不算收藏；28 張幼子禮包成功入庫後才可押。
- 每場選 1～5 個不同收藏副本，一張或兩張即可開始，不必放滿。
- 引導：選收藏卡 → 自動放入押注格 → 可取回／繼續加牌 → 核對張數與風險 → 確認開戰。
- 第一張自動單挑。輸則只沒收所選副本；贏則保留原牌、額外一張；平手保留原牌。
- 開戰前重新讀取並鎖定收藏，結算核對副本與張數，收據去重。
- 本機收藏尚無伺服器帳號所有權驗證或跨裝置同步保證。

驗證：1～5 張 × 勝敗平手共15種結算，另測空押注、超額、重複副本、未收藏、錯配與重播。UI 驗證選牌、取回及動態張數，不拿客戶收藏實際下注測試。
