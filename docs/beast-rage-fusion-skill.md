# 暴怒合體｜技能規格與素材重用檔案

更新：2026-09-13。狀態：已接入現行戰鬥核心與手機四鍵面板；實體手機尚待使用者試玩。

## 使用者已確認的方向

- 主題固定「暴怒合體」，是真正的限次增強攻擊，不只換色或假傷害。
- 只可使用己方已上陣、存活、非主戰的相生後備；後備元素生主戰元素才成立。相剋不成立，也不從整個牌庫借用未上陣卡。
- 雙方使用同一資格與運算規則，每方每場一次。不預設輸贏、不暗改傷害。
- 合體不刪除、合併或消耗收藏卡；既有押注、扣卡、獎勵與結算契約不在本次修改範圍。
- 手機優先，四鍵入口維持攻擊、技能、換卡、暴怒合體。不可用時提供簡短原因，詳細規則按需查看。

## 運算與相生

沿用專案元素：空（金）、風（木）、水、火、地（土）。相生方向為空→水→風→火→地→空；集中於共用元素模組，不建立前後端兩套判斷。

舊版 DAMAGE 額外值 38 僅為參考，並非已驗證的新版平衡值。實作須經同陣容對調雙方、不同元素與防禦／護盾情境測試後記錄採用值；不得直接宣稱全面公平。

只在實際執行合體時耗用本場次數；受控、強制補位、非法請求、重複提交不得假扣次數或假命中。舊存檔兼容與重播版本必須明確處理，不悄悄改變進行中的對局。

## 演出原則

相生能量匯聚→短暫蓄力→衝向對方→衝擊→回位。神獸本體不變；元素決定樣貌，實際戰果決定衝擊強度。不得把零傷害或小傷害演成決勝。

重用原圖、現有動畫與音效。先核對解析度，不將放大的低解析素材稱為原生 4K。手機採有限殘影與粒子、受控陰影，避免載入大量卡圖與持續閃屏。

## 接入驗收

- 核心：`tests/beast-rage-fusion.test.cjs` 檢查相生可用、相剋／倒下後備不可用、雙方對稱、每場一次、受控、舊存檔、重播和比普攻更強的實扣傷害。
- 介面：第四鍵連接核心合法動作；未達條件、舊戰局與已使用皆顯示原因。戰場按真實 RAGE 紀錄演出。
- 手機前端：在臨時隔離測試頁以 360px 實際點合體；出招後對手生命下降、按鈕顯示本場已使用，版面四鍵可見。臨時頁已移除，未動客戶收藏。
- 尚待：實體手機試玩及正式押卡完整結算。既有押卡與獎勵程式未修改。
