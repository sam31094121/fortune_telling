## 正式部署門檻

目前收藏與戰局儲存在 `data/beast-turn-accounts/`（排除 Git），用 HttpOnly、SameSite cookie 對應伺服器檔案；鎖與原子更名保護本機更新。尚非登入帳號，也不是多節點雲端資料庫。

專案有 Vercel 設定。其執行環境不能把專案本機檔案當作可靠的持久收藏庫；因此未配置時回傳 503，避免假保存或重啟遺失。`BEAST_DATA_DIR` 只適用確實掛載持久磁碟的單機 Node 部署，不能把 Vercel `/tmp` 填入來繞過門檻。

推送主線可能觸發正式部署。正式替換前必須接妥具備原子更新的雲端資料庫，或確認使用持久磁碟的 Node 主機；還需完成備份、帳號與收藏迁移驗收。目前這項未完成，因此不得將本機測試通過宣稱為正式部署完成。
