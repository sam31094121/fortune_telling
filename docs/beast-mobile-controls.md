## 戰鬥模式隔離與兩種場地

依本次使用者要求，遊戲前端只呈現戰鬥卡、操作、規則與戰果。這取代先前「戰後導向成長中心」的介面規格；持有卡片、獎勵來源、去重、押注扣卡與戰績記錄仍使用原有服務。

- `/beast-game` 自由組隊移除召喚、成長、覺醒、匯入及首頁導流。進入對戰後與抽牌戰場共用 `BattleScreen.module.css`、`BattleArena`、`BattlePanel` 與卡片能力面板；實際出招仍由 turns API 結算。
- 抽牌戰場、格鬥組陣與勝負結算不再顯示成長中心入口或領卡任務。沒有持有卡時，格鬥場提供遊戲內的免押體驗入口；試用卡不能押注，正式戰仍只押持有卡。
- 結算仍清楚顯示卡名、＋1／−1、剩餘與持有張數；保存失敗不宣稱已發獎或扣卡。相關舊測試改驗戰鬥內的持有張數，保留所有帳本與錯誤回復斷言。
- 格鬥揭牌也採固定 50/50：競技場、當前對陣與比分在上方，六張牌與固定翻牌按鈕在下方。短螢幕橫向改左右各半；規則、素材來源與略過操作可展開。使用原有遊戲牌背，不再載入大型塔羅牌背。
- 遊戲導覽、分享標題及分享圖獨立使用戰鬥內容。六元素替代規則、兵種相剋與額外同屬性加成未加入；沿用空、風、水、火、地。
