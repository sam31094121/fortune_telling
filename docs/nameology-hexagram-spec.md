# 姓名主卦與八字對照

## 使用者已確認的設計方向

姓名為主，八字為輔，卦義用於有依據的文化解說。姓名必須真正參與計算，才能稱為「姓名主卦」；只由生日與時辰決定的卦不得換名包裝為姓名卦。

本文件保存設計要求，不代表已選定傳統起卦流派、完成文獻核實或實作三方驗證。單純存檔不授權更換現有演算法或提交網站版本。

## 實作前的規則核對

- 先盤點專案既有字典、起卦程式、卦義資料與來源，核對實際公式，不僅相信註解中的「正統」等標籤。
- 選定姓名起卦方法前，記錄來源名稱、版本、頁碼或可追溯位置，以及姓名如何參與起卦。來源不足時列為待確認，不自行拼公式冒充傳統方法。
- 固定姓與名拆分、複姓、單名／多字名、筆畫字典、異體字處理、上下卦與動爻的計算及餘零規則。
- 若採產品自訂方法，須明示自訂象徵規則，不能宣稱經典認證、心理測量效度或預測準確率。

## 三層輸出

1. 姓名主卦：依經確認的方法計算，保留輸入、規則版本及可重算依據；字典缺字則要求確認，不交由模型猜筆畫。
2. 八字對照：沿用既有排盤引擎。未知時辰僅用三柱，不能補時柱；姓名五行與命盤五行的結構對照，不自動等於喜用神或改名吉凶。
3. 綜合解說：清楚標記姓名計算、八字訊號、卦義各自提供的內容。未建立跨體系對應規則前，不宣稱三者已交叉驗證；不得為了讓結果一致而改卦。

心理溝通用於解說與邀請反思，不參與命盤計算；沒有當事人自述時，不編造創傷、情緒或私密經歷，也不以讀心感應或排他關係換取信任。

## 手機呈現與驗收

### 綜合主題：靈魂特殊格局

使用者希望在易經姓名學解讀最後，呈現有溫度、容易記住的「靈魂特殊格局」。此為產品文化敘事主題，並非另算一個卦，也不是臨床人格分類。

- 先保留真實卦名，再另列「你的靈魂格局｜文化主題」。產品自訂名稱不可冒稱古籍正式格局，不宣稱罕見、唯一或天生優越。
- 主題命名須能逐項回溯到已核實的姓名字義、八字結構對照與實際卦義；缺乏來源或對應規則時只列已知依據，不補造結論。
- 簡潔呈現主題名稱、一句溫暖解說、三項依據與一個可選小行動。溫度來自具體字義與象徵的理解，不靠猜測創傷、讀心或宿命宣告。
- 例示命名「明心守衡」僅是文案形式示範；不得在未核對個案資料前當作其運算結果，也不為了套名字而改動原卦。
- 若使用者提供自身處境，可据其陳述深化解說；否認時接受修正，不把不同意解釋為隱藏性格。

此項目前為已保存的設計方向，尚非網站已接入或驗證完成的功能。

先呈現「姓名卦」「為何得到此卦」「與八字的對照」「行動參考」，細節可展開；顯示卦名、上下卦、動爻及實際起卦方式。若現階段只算生辰參考卦或字串象徵卦，維持真實名稱。

- 同輸入、同規則版本可重算一致；模型只解說，不更改卦象。
- 覆蓋複姓、異體字、未知字、已知／未知時辰與曆法邊界。
- 依所選方法驗證改名如何影響計算，不要求每次改字必然換卦。
- 前端、後端與暫存攜帶一致的規則版本；舊結果不可混用新依據。
- 分開回報：規範已存檔、規則已核實、程式已接入、測試已通過。通過畫面測試不等於傳統來源或預測效度已驗證。
