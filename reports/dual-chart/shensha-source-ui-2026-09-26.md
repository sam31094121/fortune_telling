## 已實作

- 雙命盤與獨立八字頁都依 `coreReady + status=VERIFIED + ready + outputStatus=READY` 顯示命中項目。缺少新輸出政策的舊結果不放行。
- 已核對但沒有命中：雙命盤保留空格；獨立頁不列該柱神煞。不顯示「未命中」文案。
- 真正來源衝突或 `BLOCKED_VARIANT` 列為分歧限制；其他未放行項目另列待核。名單為空則不顯示該段。
- 「本書取法已核對」與跨書對照分欄，沒有把 VERIFIED 解釋為各流派一致。
- 「查看依據」按項目使用實際原文來源與頁碼；缺少出處或定位，不生成空依據連結。
- 英文使用 shensha，沿現有介面語言設定；沒有新增全站切換器或強制雙語。原典引文與規則說明保留來源原文。
- 手機說明在命盤水平捲動區之外自動換行，14px 字級；依據連結與展開入口至少 44px 高。A4 使用同一份資料與共用文案，精簡英文而不縮小字級。
- UI 只讀後端規則資料，不新增排盤、AI、來源網路請求或計時輪詢。詳情使用原生 details；四柱元件本機 React SSR 50 次共46ms，這不是客戶端整頁或真機效能保證。未做完整產品效能基準測試。
- 語言切換會撤銷舊 PDF 連結；若 PDF 製作途中語言改變，丟棄該次結果並提示重做，避免語言版本錯配。
