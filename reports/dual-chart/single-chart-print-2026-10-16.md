# 神煞易經單張列印（2026-10-16）

本輪業主指定：八字、紫微分別選擇，每次只輸出所選命盤一張 A4，提供友善引導；不發布遠端。

施工前證據：`DualChart.tsx` 的 printSelection 預設同時勾選八字、紫微、神煞、易經；列印結果區還包含一個 `.panel` 選擇操作區。`dual-chart.module.css` 的 `.printPreview .results>.panel` 將該操作區也套成至少 297mm 的紙張，列印媒體未排除它。PDF 只擷取 article，與瀏覽器列印的選取範圍不一致。

影響：進入列印預覽即同時準備兩盤，瀏覽器列印可能另印操作區；四個勾選項中神煞／易經沒有獨立頁輸出，提示與行為不一致。

限定修復：本卡列印選擇、引導與紙張容器，必要 PDF 防護及回歸。保留命盤內容、算法、神煞取法與其他卡片；保護工作區既有變更。

## 修復

### 本輪追加：五行下方解讀

業主先授權補全強弱、喜用神、忌神，後明確擴充為六項：強弱、喜用神、忌神、格局、天運五行、星座。最終授權此卡顯示既有本站取法結果，即使原典來源仍有分歧；不改共用來源狀態或其他卡片守門。施工前五行下方僅有日主、命身宮等摘要。本輪沿用同一客戶後端結果；核心未就緒或缺值不造值，不放血型／未提供佔位，也不重複原摘要。指定的本派參考說明與相鄰「查看取法來源」入口均不在畫面或列印顯示。內部依據與限制見下方最終驗證。

- 結果區提供「列印八字」「列印紫微」兩個入口；預覽只保留一個 article，單選切換，保留彩色／黑白與下載 PDF。
- 刪除被套用 A4 樣式的重複選擇操作區；短提示只留在不列印的工具列。
- PDF 拒絕零頁、多張、過高及內容溢出的輸出，不裁切或壓縮命盤。
- 紫微只調整列印的行高下限、註記間距與上下留白（5mm，左右8mm），保留全部宮位、星曜、大小限及來源註記。
- 全站 print CSS 的 `svg { display:none!important }` 是五行圓環／圖例消失的原因。本卡列印局部恢復這兩種 SVG，不改全站規則；彩色扇區、黑白紋理與比例仍使用原資料。
