# 阿修羅限定提交批准

業主在得知本輪阿修羅測試與建置通過、全站仍有三項既有稽核及一項其他入口逾時後，明確批准「這一批先批准，提交阿修羅測試」。本次僅提交阿修羅三步引導、首頁接線、等待／動畫／音效穩定性、對應技能登記與測試記錄。

此為本批限定發布例外，不代表全站健康通過，不變更既有稽核或來源狀態，也不授權帶入其他卡片的未提交修改。其他遊戲、八字、紫微、配對、審查政策等本機工作保持原樣，排除於本提交。

已完成驗證：實際後端資料對應、前端生命週期、Chromium 與 WebKit 手機模擬、四倍 CPU 降速八輪、離線手動重試、背景模擬返回、30 秒逾時與晚回應隔離、資源清理、型別及正式建置。詳細證據見同目錄各阿修羅驗收報告。

已知限制：實體安卓／iPhone、作業系統 App 切換與發熱未驗收；既有全站三項來源／取法稽核未過，其他入口 API 複查仍逾時。歷史報告的「未提交」是當時狀態，本次批准由本記錄補充，不倒改原結果。
