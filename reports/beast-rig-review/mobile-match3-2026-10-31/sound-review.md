# 困難寶珠戰：分層柔化音效

## 限定授權

業主要求聲音有邏輯、配合動畫，並柔和、不刺耳。只修改困難寶珠戰介面提示音；不改卡片能力、傷害、等待時間、簡單版原有提示音或神獸登錄叫聲。

## 實作

- 有效連珠依實際傷害分成輕清除音或蓄能音；只消除不播放命中音。
- 神獸命中由主要攻擊者實際動畫幀觸發，對準既有咬合時間；未就緒／減少動態用當次卡片受擊呈現，晚載入不重播。
- 單盾清場、三盾合體、敵方反擊與防護各用不同音型，每段不超過 780ms。
- 最高基頻／掃頻 1320Hz、22ms 柔起音、2200Hz 低 Q 濾波；不增加音量。已開始音源停聲用 9ms 淡出、10ms 停止，未開始者立即取消。
- 真實指標／鍵盤操作解鎖音訊。未解鎖時略過，不排隊補播；靜音、頁面隱藏、離場清理音源，離場關閉 AudioContext。

## 驗證

- fake AudioContext 單元測試驗證頻率／包絡／音量邊界、七種音型、解鎖、受阻 API、淡出／未開始取消、重複停止、節點清理及 dispose。
- 獨立 Edge 使用真實 DOM 指標事件與原生 AudioContext，只包裝 API 記錄時序。普通攻擊有蓄能→命中→反擊；高門檻三珠零傷害無命中音；靜音後不再新增音源；返回首頁關閉 context；減少動態仍有對應受擊音。
- 主要神獸從動畫啟動到命中音實測 1129.5ms，只觸發一次；既有命中基準為 1120ms，差異為取樣幀間隔。
- 單盾與合體採明示盤面／魔法珠 fixture。單盾必須真拖兩顆同屬性普通珠加一顆盾，辨認完整 660／990／1320 音組；不能只以與蓄能重複的 660 判定。
- 三盾完整音組 440／550／880／110，接防護音、無命中音。最新淡出版真點靜音：三個已開始源在 10ms 停止、一個未開始源立即取消，後續沒有新 start，無 JavaScript 例外。
