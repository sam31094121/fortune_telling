# 寶珠戰手機角落碰撞與兩側入口驗收

## 本輪範圍
- 單卡左／右真實三角碰撞；後端判定外側落空，不強制接取。
- 單卡只留對應武器，右側沿用手動能量寶珠；手機兩側同為56×64px觸控區。
- 盤面最多上移24px，不縮寶珠；釘子止於卡片上緣外。右寶珠無方框、無新增常駐動畫。
- 入庫對準持有者、元素、武器種類。獎勵與傷害仍以後端為準。
- 普通連線停留縮短，慢速法珠儀式維持。
