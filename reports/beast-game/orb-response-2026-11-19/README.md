# 寶石捷連線：即時盤面、後端裁判與接珠回饋

本輪只修改寶石捷連線及其攻擊技能檔、相關測試。

- 放手保留路徑高亮；前端使用既有連珠規則試算消除、連鎖及補珠，與請求並行播放。後端回傳裁判結果，通過才接續權威血量與獎勵；不一致取消預演並改播權威結果，拒絕操作恢復確認過的盤面。預演不發獎、不存檔、不自動花費寶珠攻擊次數。
- 單卡武器列不得為了塞進短畫面向上覆蓋棋盤，棋盤尺寸變更會重新量測；放不下時不能鎖住捲動。
- 接珠沉到卡框底部再進入寶物，逐顆顯示後端提供的實際庫存數字與發光，不等整批結束。

## 驗證

- 型別檢查、最終正式建置通過。第一次建置遇裁判回覆泛型不相容，修正後完整重建通過。
- 100 組盤面試算與真正後端運算一致，輸入未被修改；裁判測試涵蓋 100 組通過、100 組不一致、100 組無預演。
- 最終慢網路瀏覽器測試：320、390、1440 寬度及減少動態共四組通過；消珠配對在後端回覆之前已開始，最後盤面、傷害與事件仍符合後端回覆。
- 兩組故意更換後端種子測試通過，會取消原預演並回到後端盤面；兩組拒絕操作測試通過，生命、回合與盤面均不被預演更動。
- 390×580 短螢幕連續六組通過，武器未覆蓋棋盤且仍在畫面內。首次短螢幕檢查曾見位移斷言失敗，後續保留幾何證據並連續重測；不宣稱所有實體手機已驗收。
- 掉珠物理、每顆入庫回饋、播放器暫停與取消清理、遊戲公平性測試通過。
- 全站健康檢查 64/66：原兩項已獲暫緩的來源檢查仍失敗，並未改成通過。神獸入口一次逾時、掃描重試通過，之後單獨重測亦通過；保留 flaky 紀錄。未擴修其他功能。

## 限制

前端預演只涵蓋盤面，血量、反擊、掉珠歸屬及庫存仍由後端結算。預演可遮住部分往返等待，不能消除冷啟動、網路斷線或手機效能瓶頸。測試是本機瀏覽器與手機尺寸模擬，並非正式站恢復或所有實體機通過的證明。舊正式站停用事件不在本輪恢復範圍。

測試報告不保留戰局憑據。各資料夾記錄其當時版本；`referee-final` 為最後四組裁判流程驗證。
