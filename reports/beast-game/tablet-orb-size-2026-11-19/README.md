# 跨裝置盤面尺寸與文字列

重現：768×1024及1366×768，一隻與兩隻盤面尺寸不同。大螢幕原本使用block外殼最小高度作預算，單隻武器高度和手機限定隱藏的狀態／援助框也影響版面。修正：hard45使用實際區塊量測及固定五欄基準預算，排除自動留白；平板也使用flex排版；戰鬥狀態文字僅供讀屏，支援結果與攻擊說明在戰鬥隱藏、說明展開時可看。單隻大螢幕另留武器高度。

驗證：768×1024、1024×768、1366×768、320×580各一至五隻，共20組開場排列，盤面尺寸一致、無橫向溢出、卡片與武器在視窗內。獨立訪客測試，沒有出招或客戶收藏操作。型別通過；防抖與建置結果待補。仍依業主要求留本機待合併發布，未推送。

建置通過（既有警告保留），八種高度靜止與捲軸切換均零位移。320×580與1366×768另外逐一驗證整頁scrollHeight不超過視窗高度，無需上下捲動；此為瀏覽器尺寸模擬，非所有實體裝置保證。本輪未重跑全站健檢，正式發布前仍需核對。
