# 一至五隻自由組隊

限寶石捷連線 hard45；原本困難 II 與其他遊戲的人數門檻不擴改。

玩家親選主角後可直接用單隻開場，或自行加零至四隻夥伴。後端 profile、開場、回合及寶器讀取核對實際隊伍長度，不自動補卡。既有對手五隻、傷害與獎勵不變。單隻沿用最後存活大卡，兩至四隻按數量置中排列，五隻保持原版。

驗證：型別、建置、既有 campaign 存檔測試通過。新 API 測試一至五隻開場並保存原卡順序、對手仍五隻；零隻、六隻、重複、缺主角及未知卡拒絕。390×844 與320×580 共十組開場排列通過，卡片無重疊、無橫向溢出。只展示開場，未代用戶操作攻擊；測試使用獨立訪客資料。

右側提供實測截圖切換，並非把靜態預覽冒充實際戰鬥。正式部署未核對。全站健檢結果另附。

追加回歸：修正武器固定五欄造成的四卡不對稱；兩至四卡與武器使用相同欄寬、間距。320×580 曾重現單隻與兩隻盤面尺寸差異，改為以五欄基準計算盤面預算，神獸依剩餘高度縮放；390×844 及320×580 的一至五隻盤面寬高一致（容許一像素捨入）、武器與卡片中心對齊。八種高度的防抖、捲動切換均零位移。建置成功，既有警告仍保留。

最終全站健檢65/67，warnings0、flaky0；失敗僅既有 BAZI_SOURCE_REGISTRY_COMPLETE 與 DUAL_CHART_SHENSHA_DISPLAY，依業主先前明確豁免不阻擋本輪遊戲提交，未改算通過。先前舊測試限制至少兩隻才放大的失敗已保留，更新成單隻開場規格後完整 replay 回歸通過。未新增其他功能變更。
