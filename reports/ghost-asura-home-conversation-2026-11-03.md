# 阿修羅首頁主卡補接既有三步追問

## 修改前缺口與限定範圍

首頁入口 `/ghost-asura` 的 `GhostAsuraPageClient.tsx` 目前顯示主卡與 `AsuraVoiceCard`，沒有技能頁已完成的 `AsuraConversation`，因此客戶從首頁進入看不到「結論 → 依據 → 行動」引導。

本輪只在主卡成功、顯示契約正確、後端清單核對通過、實際已知時辰且非年齡限制結果後，重用既有追問元件。沿用成功請求當次同一份生辰快照，姓名、時辰、身分及其他已送欄位不重新由目前表單拼湊。換資料、重新解盤、身分切換或離頁清除舊對話；不自動發送追問。

必要檔案：主卡客戶端、共用追問輸入型別、主卡處理函式測試、本報告。既有後端 API 與資料契約保持一致；不改公式、來源、其他卡片或新增自由聊天能力。

## 驗收

待驗：首頁已知時辰結果才掛載、未知／未核對／限制結果不掛載、請求快照一致、換人與過期回應不能恢復對話、原有主卡與追問生命週期回歸。

## 修後程式驗收

- 主卡成功請求只建立一次 `submittedInput`，傳給讀取 API 並保存為既有 `voiceBody`；追問直接沿用同一物件，不讀後來的表單值。
- 已知時辰且後端核對通過才顯示既有追問入口；未知時辰、核對未過與年齡限制保留原卡結果，不開啟追問。只有點入口才開始請求。
- 切換本人／親友身分會取消舊排盤並清空結果；晚到回應不能恢復另一人的對話。原有換資料、重新解盤與卸載取消機制保留。
- `node tests/ghost-asura-page-flow.test.cjs` 通過：包含首頁掛載、完整請求快照逐欄一致、身分切換、晚回應與三類不可追問結果。
- `node tests/ghost-asura-conversation-flow.test.cjs`、`node tests/ghost-asura-skill-reading-flow.test.cjs` 通過；`npx tsc --noEmit`、兩個元件 ESLint 與 `git diff --check` 通過。
