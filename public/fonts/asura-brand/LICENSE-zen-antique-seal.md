# zen-antique-asura-seal.woff2

- 用途：鬼魅阿修羅卡頭「修羅」印文（僅兩字子集：修 U+4FEE、羅 U+7F85）
- 字型：Zen Antique Regular（Zen Antique Project Authors；明治期金屬活字風格的古風明朝，厚重、刻印感）
- 授權：SIL Open Font License 1.1（全文見同目錄 `zen-antique-OFL.txt`）
- 來源：https://github.com/google/fonts/tree/main/ofl/zenantique （上游 https://github.com/googlefonts/zen-antique）
- 製作：fontTools pyftsubset 2026-10-04，`--unicodes=U+4FEE,U+7F85 --flavor=woff2 --no-hinting --desubroutinize`
- 說明：遍尋 OFL 授權的隸書／篆書字型未果（免費可商用隸書極少，多為商業或 GPL），故採此古風刻印感字型；未修改字形，只做子集。
