# 《技能戰鬥檔案》

版本 1.0.0 · 共 60 張戰鬥卡

## 產品功能（已列入）

| 功能 | 說明 |
|---|---|
| **戰鬥功能** | `/beast-game` 翻牌對戰，讀本檔驅動衝鋒／命中／隨時戰鬥 |
| **神獸卡片戰鬥功能** | 神獸卡出戰時讀 `cards/{poolId}/skills.json` |

## 技能定義

| 技能 ID | 名稱 | 類型 | 說明 |
|---|---|---|---|
| `skill_charge` | 本體衝鋒 | approach | 蓋牌翻開時，本體以 3D 立體從己方牌位衝向對方牌位交戰 |
| `skill_hit` | 命中衝擊 | impact | 衝鋒抵達對方牌位時的命中特效 |
| `skill_ready_battle` | 隨時戰鬥 | passive | 資產就緒後可隨時呼叫進戰鬥，無需現場生成；戰鬥卡技能檔已登錄即可出戰 |

## 戰鬥流程

1. 蓋牌翻開 → 觸發 **本體衝鋒**（`skill_charge`）
2. 抵達對方牌位 → **命中衝擊**（`skill_hit`）
3. 被動 **隨時戰鬥**（`skill_ready_battle`）：資產在檔案內即可隨時呼叫，不必現場生成
